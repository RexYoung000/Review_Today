## 实际导出限制

2026-09-05：网页导出菜单提供 128/256/512 px、复制 SVG、下载 SVG、下载 PNG；本次内置浏览器的下载事件没有生成本地文件。原生“复制 SVG”已成功核对。使用浏览器资源导出能力保存页面实际生成的 SVG 几何，保留原件，再机械添加与网页相机相同的背景/尺寸元数据。PNG 从矢量渲染，**不是 OneWorks 下载的 PNG，也不是截图放大**。若后续直接下载通道恢复，应补留原生文件及校验值。

`originals/*.svg` 保留网页几何原件；`exports/*-icon.svg` 与各尺寸 PNG 是带背景的交付版本；透明版仅保留角色；`parameters.json` 和 [编辑链接](editor-links.md) 保留参数，不冒充工具工程文件。只改变封装和输出尺寸，不重画角色路径。原生“另存为”也未取得可交付工程文件。
