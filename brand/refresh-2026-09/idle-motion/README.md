# 吉祥物待机修订：竖立阅读与夸张弹性

2026-09-07，v2 已实现并接入待处理空态，待 Rex 视觉验收。原始 v1 记录及视频保留在 Git 历史（4488349）。

## 当前表现

- 黑色和银白主体均为白眼白、黑瞳孔。银白主体只有约 1 pt 中性深灰眼眶，随眨眼形变，身体无外描边。
- 左右看看 4 秒轨道保持原样。伸展 3.6 秒，先蓄力，再从底部拉长至约 140%，配合宽度收窄、顶部和脸部延迟，再压低回弹。弹跳 3.2 秒，约 75% 高度蓄力、身高 35% 的跳高、落地挤压和小回弹；阴影不离地，随高度缩小变淡、落地扩宽恢复。
- 阅读 8 秒：合上的本子从身后绕右侧取出，在身前竖立展开；纸页朝角色，外封面朝观众，阅读、翻页、合上再绕侧收回。保留无手造型。R 从现有透明母版直接派生单色纹理，保持斜切、不镜像。封面、封底、书脊、纸页边缘与翻页为独立 Spine 附件。
- 可见本子全程不透明，禁止渐显及从零放大。1.1 秒/6.9 秒在完全离开身体轮廓的侧面切换前后绘制顺序；开始、结束时完全遮挡，再隐藏道具。阅读时书页最高点低于眼睛。
- 首次等待 1 秒；每段完整结束后停顿 1.5–3 秒，从另外三段等概率选择，不连续重复。停顿只轻微呼吸。隐藏暂停、恢复不追赶；销毁后重新进入重新选择；减少动态效果立即静止并收起道具。
- 待处理画布为 150×170，保留原 150×125 画布下的角色静止大小。时长和固定取景在 `idle-definition.mjs` 共享，无逐帧镜头缩放。
- 原始身体网格、权重、前 14 个骨骼、思考/语音及左右看看轨道逐项比较未改变。此次只重制三个待机轨道与道具。
