# 内置 ImageGen 原始提示词

## A 回忆折返

Use case: logo-brand.
Create one polished landscape brand identity concept sheet, 1536 x 1024 if possible, for "Review Today", a native macOS personal learning coach for adults. This product helps people deeply understand a subject, connect new knowledge to previous learning, then retrieve it through active recall and spaced review. The brand should feel intelligent, quiet, precise, human, and memorable.
Design discipline: exceptionally simple flat vector-like geometry, high quality intentional negative space, no illustration. All instances on the sheet MUST use EXACTLY the same logo silhouette. Mature humanist sans-serif wordmark with precise spacing, exact text "Review Today". Do not add a tagline. Use the same baseline type treatment for the wordmark throughout.
Palette: warm near-white #F7F6F2, graphite #272B2A, restrained deep teal #246C63. These are concept colors coordinated with an existing pale neutral/graphite/teal macOS product, not an app-wide palette change. Must work in a single solid ink.
Layout: restrained editorial concept board with generous blank space and no decorations, no fake interfaces, no photographs, no stationery mockups, no presentation perspective. Top-left small discrete option label. Upper central band features the large standalone graphite logo on off-white, with a medium horizontal symbol + "Review Today" wordmark lockup next to it. Lower band features TWO app-icon studies side by side, each a rounded square viewed dead straight-on at the SAME size: warm white icon with dark teal logo, then deep teal icon with warm white logo. One subtle hairline edge, absolutely no bevel, gradient, glass, drop-shadow, texture or 3D. Logo occupies about 58% of the square, optical center with ample padding. At the bottom right add a small-size row repeating this exact same silhouette in one solid dark color, with no extra text or numeric size claims.
Forbidden: faces, eyes, heads, hands, mascots, animals, robots, brains, graduation caps, speech bubbles, sparkles, stars, light bulbs, checkmarks, infinity symbols, decorative dots, multicolor pieces, leaf/growth imagery, stock book pictograms, ornate monograms, childish bubbly type. No inherited cartoon shapes. No circular refresh arrows. This is a new identity, not an edit of earlier images.
Direction A. Exact small option label: "A / RECALL". The core mark is a custom abstract lowercase r / uppercase R hybrid built from ONE bold continuous returning stroke. A compact asymmetrical silhouette: a confident short vertical spine, a softly squared upper loop whose path turns inward, and one clean diagonal outgoing terminal at the lower right. The broad inward return expresses actively retrieving something previously learned. Give it ONE unmistakable diagonal negative-space incision that makes the bowl and the outgoing leg feel like a continuous returning path, not a standard letter from a font. Keep the central counter generously open. Flat single-color silhouette with carefully controlled small corner radii, not a thick outlined drawing, not a maze or a spiral, not a generic sans-serif R with an arrow attached. Aim for an immediately graspable 2-second silhouette; simple enough to draw from memory. Do not add any separate dot or arrows. This is the primary recommended candidate: reductive, unusual, adult, editorial, purposeful.
