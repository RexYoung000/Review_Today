## 当前：四态整合，无投影

按 Rex 确认的方向，语音页四态现在共用角色比例与弹性表面。聆听的波峰从两端向内汇聚，角色被托动、轻微倾听；回答的波峰从中间向外传出，角色有主动压缩发力。思考保持舒缓跳跃，快慢不对应真实思考量。语音场景移除所有投影；独立 recall 环绕保持不变。

停止会取消新跳跃，当前空中姿态原地缓降；聆听/回答停止时补一次轻微收势，身体回到自然轮廓，眼神归中，声浪和余波平息。无声时不持续做假声量动作；减少动态效果保持静态角色与低条波面。

宽预览（画布 ≥ 520 px）增加左右各 2 条低幅波条，共 19 条，间距保持 20 px；窄窗与紧凑预览仍 15 条。角色主要活动范围不随边缘延长而扩大。

[evidence/voice-four-states.mp4](evidence/voice-four-states.mp4) 是 14 秒离线连播：0–3 秒聆听，3–6.8 秒思考，6.8–10.8 秒回答，10.8 秒停止。视频经 MCP 的 `animation: conversation` 生成，使用与浏览器同一状态和绘制逻辑，非 UI 录屏。页面可直接打开视频。下方旧视频保留为历史对照。

14 项自动化检查通过，包括传播方向、无投影、布局条数、网格稳定、裁剪同步、快速切换、静音、停止平息。浏览器检查宽窄布局、四态操作、零声量、深色及减少动态效果；当前仍未接真实语音或原生 App，四态程序动画尚未烘焙进下载的旧版 Spine JSON。

## 前版：弹性接触试作

Rex 否定上一版角色与波浪各动各的表现，提供跳跃小球参考，并确认本轮先验证「思考跳跃 → 落地 → 停止」。打开 [语音预览](http://127.0.0.1:8769/voice.html) 默认运行新思考动作；下面的语音修订为前版记录，聆听/回答仍保留供对照，尚未按接触方向整合四态。

- 角色约为 2.4 根波条间距宽；预压、伸展、落地挤压驱动骨骼与下部局部 FFD，眼神预判下一落点。
- 波条采用固定 120 Hz 弹簧计算，局部压力与落地冲击导致下陷和余波。角色底部以实际变形后的网格最低点对准插值波面，避免固定悬浮间距；投影落在同一波面上，随腾空扩散变淡。
- 跳跃轨迹是确定性表演，波面与身体共享接触状态，不宣称完整刚体物理。停止立即取消新跳跃，在当前横向位置缓降约 0.32 秒，接住后余波自然衰减；减少动态效果保持平静表面与静态角色。
- `wave-contact.mjs` 为浏览器和 MCP 离线渲染共享的源。当前程序式接触/FFD 尚未烘焙进 Spine JSON，页面下载明确标记为旧版语音循环；独立 recall 环绕数据没有变化。
- 新增 `preview_frame` / `preview_clip` 的 `animation: thinking` 选项，渲染 8 秒示例，在第 4.8 秒请求停止。`evidence/contact-thinking-stop.mp4` 是离线渲染，非 UI 录屏；`contact-airborne.png` / `contact-land.png` 是阶段参考。

验收：观察落地时脚下波条下陷与身体压扁是否像同一件事；半空点击「停止」，应就地落稳，余波消失后再次点击「思考」可重新起跳。13 项检查通过，含 900 帧网格/裁剪采样、不同时间停止后的坐标连续与平息、减少动态效果。浏览器检查了宽窄布局、落稳、深色、减少动态效果；未执行原生 App 或 Spine 编辑器验证。

## 前版：语音修订

入口：[语音波浪](http://127.0.0.1:8769/voice.html)，顶部可切回思考小样。沿用深青绿主体与浅青绿波浪，保持旧波浪上方的点的位置；大预览角色约 100 px，紧凑示例约 43 px，均包含小幅活动与底部投影，不代表扩大原生占位的决定。

- 「聆听」：克制的局部倾动、独立瞟动与眨眼；「回答」：身体两侧错拍起伏，头顶与面部稍有跟随延迟。两条 4 秒循环含骨骼与加权 FFD，写入同一 JSON。
- 同一模拟声量包络驱动波浪、身体形变强度、少量抬升与投影浓淡。投影落点固定，角色抬升时阴影收窄变淡。声量突然变化时快速跟进、平滑收住。
- 「思考」复用已确认的 recall 环绕；状态文字在点击时更新，动作平滑混合。「停止」或语音声量降至 0 后收敛为静止；减少动态效果时只有静态角色、基线和状态文字。
- `voice-scene.mjs` 是浏览器与离线 MCP 渲染共享的声量/状态混合及波浪逻辑；导出 JSON 包含循环与已有投影附件，实时声量驱动和波浪绘制仍需要宿主逻辑，不是 JSON 自带真实语音识别。
- 使用 `motion_author` 可共同调整身体强度、眼神、权重、波动和采样密度；`duration` 与 `bend` 仍用于 recall。语音页在打开/刷新时读取当前 MCP 版本；不打断正在看的语音状态自动换版。
- 通过真实 MCP 生成 `evidence/voice-speaking.mp4`（8 秒模拟回答）及 PNG，视频是离线运行时渲染，非浏览器录屏。

验收：依次点「聆听 → 思考 → 回答 → 停止」，也可快速来回切换；把声量拉高再降至 0，检查停止后的波浪和身体是否稳定。浅深主题与减少动态效果可在顶部切换。已在 465 px / 1280 px 浏览器检查布局、四状态、零声量、快速切换和减少动态效果；11 项自动化检查通过，含两条语音循环无网格翻折、首尾闭合、形变确实超出骨骼移动，以及静音/停止稳定性。Spine 编辑器与原生真实语音尚未验证。

## 验收路径

1. 「播放小样」：瞳孔先左瞟并短暂眨眼，身体随后发生局部弯曲，右侧分出小块绕行，最后重组回弹。
2. 「半速观察」或拖动时间轴，在 0.45 s、1.25 s、2.48 s、3.17 s、4.6 s 比较眼神、身体轮廓和碎片位置。
3. 勾选「显示网格与骨骼」「显示身体权重分布」，看到局部顶点变化与 3 区权重。
4. 在分离中「立即收拢」：文字立即响应，当前姿态向静止姿态混合约 0.22 s；可重新播放，不等待一圈结束。
5. 开启「减少动态效果」：停止循环、收拢为静止，时间轴禁用，状态解释仍存在；手动开关与系统媒体查询关联。未执行原生系统设置切换或 VoiceOver 端到端验收。
6. 改身体/眼神幅度后「生成并预览」：保存新版本并更新下载。原版仍在 `data/mascot.json`；MCP 修改也会同步到可见网页。

## 文件

- `recipe.json`：当前已提交的制作参数；非用户已验收的最终动效数值。
- `data/mascot.json`：可编辑骨架、加权网格与 4.2 形变时间轴。
- `data/images/`：atlas 和图像源，身体 RGB 图由网格轮廓裁剪显示，非透明 PNG 拆件。
- `assets/`：去眼生成素材、眼白/瞳孔/碎片的可编辑 SVG 及保守身体轮廓。
- `evidence/recall.mp4`：官方运行时骨骼计算 + Canvas 光栅适配器生成的 5.6 秒视频，非原生录屏。
- `evidence/bend.png`：从 MCP 图片反馈取得的关键帧（最终光栅修订后重新渲染）。
