## HTML 优先展示

原生小样保留为历史验证工具，现已收起。需要恢复历史对照时才运行 `bash tests/mac/run-brand-material-preview.sh`，打开生成的 `output/brand-material-preview/ReviewTodayBrandMaterialPreview.app`。顶栏「试作版」开关比较当前配色与纯黑白；「界面／动效／控件」分别检查页面、四态、旧角色与知识卡。浅深切换与减少动态效果均可操作。

「小样」菜单：默认窗口（⌘⌥1）、紧凑窗口（⌘⌥2）、保存当前页面截图（⌘⌥S）。截图只导出小样自身的原生视图，不截取其他应用。默认 1280×820，紧凑请求 760×660，系统按内容最小高度调整；窄窗保留滚动和侧栏收放。

界面页点击侧栏「RAG：理解检索与生成的边界」查看完整正文、表格与流程；知识库等主入口沿用同一内存样例。可以输入草稿、打开学习方式/思考强度菜单；发送始终禁用。

网页动效使用 `node tools/mascot-motion/src/build-material-preview.mjs` 生成 `output/material-web/index.html`，可通过本地静态服务器打开。和原生组件共享 material、mesh renderer、voice contact 与 native player 源文件；不是另一套动画。
