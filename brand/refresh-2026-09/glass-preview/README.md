## 制作方式与当前证据

- **Icon Composer 工具链已跑通**：清除了未完成导入的重复应用实例；在 Xcode 随附 Icon Composer 中导入现有母版并保存基础工程。随后调整原生 `.icon` 文档的填充、比例及材质，在软件中重新打开、检查图层并再次保存。材质由 Apple 渲染器生成。
- **图标已查看**：Icon Composer 中实际检查默认、深色、单色外观和 68% 图层比例；由同一保存后的文件导出 3 × 7 张 16–1024 px PNG，默认/深色/单色对照板已人工查看。Mono 使用当前工具的 `Mono` rendition，未把旧 TintedDark 染色输出当作单色成品。
- **材质参数**：原始 R 图层为 `#246C63`、缩放 0.68；组透明材质强度 0.12、原生高光开启、中性阴影 0.28。中性渐变为默认背景；当前 Icon Composer 1.6 自动生成深色与 Mono 外观。没有携带该版本保存时会丢弃的旧 specialization 配置。
- **界面代码已实现**：共享配色变体及默认关闭的操作层材质；独立小样应用标识 `Rex.Review-Today.GlassPreview`、强制内存 fixture、发送禁用、现有长正文样例、原版对照及减少效果演练。日常 App 不启用预览环境值。
- **原生补查**：修订后的侧栏宽度已实看为 248 pt，品牌标题完整。已查看浅深主题的起始页与长正文会话页；会话操作浮层开合、Escape 回到输入、学习方式选择「知识整理」后关闭菜单并恢复输入焦点和保留草稿均有实际 AX 状态。深色下勾选减少透明度、减少动态效果后，自定义操作组使用稳定实底。发送保持禁用。
- **自动化通过**：新小样契约覆盖默认不开启材质、减少效果分支、黑白正文/辅助字/品牌色对比度、两个强调角色同色，以及预览输入不得发送/创建消息。品牌色对主画布对比度浅色 5.72:1、深色 8.93:1；三种实底上的普通文字和品牌色均至少 4.5:1。
- **回归通过**：既有 `AppRuntimeContractTests`（运行入口/存储/网络身份与预览禁止发送）和 `InteractionFocusTests`（焦点与选中状态独立、浅深色及禁用态）通过。21 张图标的尺寸、Alpha 及四角透明检查通过。
- **构建通过**：Xcode 26.6 (17F113) 的日常 Debug 签名构建及 `codesign --verify --deep --strict` 通过；只构建到独立输出目录，未启动或替换日常构建。独立小样构建及签名检查通过，签名与应用标识的区别仅用于隔离小样；项目签名设置、最低系统版本和默认图标资源未修改。
