# Review Today Logo 与 App 图标重新探索

2026-09-06 · 静态视觉候选，等待 Rex 选择。

## 本轮目标与依据

- 用户要求：现有设计过于幼态，需要更简洁、更独特、更贴合产品。
- 产品事实：当前是 macOS 个人学习教练，帮助理解知识、关联已有学习经历，经确认形成知识并进行主动回忆。不是儿童教育、通用聊天或纯笔记收藏工具。
- 当前视觉事实：V8 使用大头、呆毛、笑脸、手绘描边与卡片；OneWorks 两版也保留五官。减少同类角色细节仍可能保留幼态，因此本轮探索纯符号。
- 继承：安静的学习编辑台气质、暖白与石墨基础、青绿协调色；当前产品名仅用于字标组合预览。
- 历史 Opal 案例只借鉴「符号表达核心任务且贯穿产品」的方法，不采用宝石造型，也不扩展 onboarding 或商业化。

## 两种视觉假设

| 候选 | 产品含义 | 造型目标 | 需要检验 |
| --- | --- | --- | --- |
| A 回忆折返（推荐） | 把理解过的知识重新提取出来 | 宽笔画 R，上部向内折回，斜向切口将回弯与右下笔画分开 | R 与折返的识别是否自然，是否过于像通用科技标志 |
| B 知识连接 | 新理解与已有知识建立关系 | 两个相向、错位的钩形组成紧凑符号，中部留出阶梯状负空间 | 抽象含义需要建立，小尺寸的细缝有合并风险 |

本轮交付视觉方向：logo、Review Today 字标组合、App 图标及浅深与缩小预览。使用内置 ImageGen，原始提示词和输出随本目录保存。不用代码重画生成图形。精确色值、字距、轮廓和小尺寸光学校正仍需选定后收口。

## 可见交付与检查结果

- [A 回忆折返](a-recall.png)：1536 × 1024 px 原始模型输出；单色符号、字标组合、浅底/深青绿底 App 图标及模型绘制的缩小示意。
- [B 知识连接](b-connect.png)：同尺寸原始模型输出；同一组使用场景。
- [初始提示词](prompts.md) 与 [定向修订提示词](refinement-prompts.md)：均使用内置 ImageGen；没有使用 API/CLI 或 OneWorks，也没有人工矢量描摹。
- `iterations/` 保存首轮未采用的预览。首轮画布有非预期透明区域，深色标志难以阅读；第二轮恢复清晰浅底，B 同时重做为相向钩形。

人工查看了正式交付两张图：去除了五官、角色和手绘描边；Review Today 文本正确；单色与反白均可读。A 的字母与折返关系较直接，因此优先推荐；B 更稳重，但连接含义较抽象。

这两张是方向稿，不是独立透明 logo、矢量文件或 1024 px AppIcon 母版。图内缩小行由模型生成，**没有冒充从同一母版导出的实际 16/32 px 测试**；正式小尺寸像素检查仍未完成。A 的斜缝、B 的两处细缝以及图内残留的轻微表面明暗均需选定后收口。浅/深图标不是原生浅/深主题或 Dock 运行证据。

验收时先看图中的大符号是否愿意长期使用，再看与 Review Today 的组合是否成熟、两种底色是否合适，最后比较缩小示意的轮廓。Rex 选择：待确认。尚未宣称方向已对齐或用户已接受。

## 采用边界

正式 V8、AppIcon、侧栏、产品配色与吉祥物动画均保留。选择方向后再制作正式可交付母版及对应尺寸，并在实际 App/Dock 中验收。本轮静态稿不代表原生适配已通过。
