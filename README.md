# Review Today

Review Today 是“个人记忆教练”的项目仓库。产品把每天零碎输入的学习内容自动整理成可复习的知识点，并通过主动发起的结构化语音问答帮助用户形成长期记忆。

## 当前阶段

- 阶段：21 天自用 POC，需求边界已完成首轮对齐，尚未开始功能实施。
- 首轮用户：Rex 本人。
- 首轮平台：macOS 原生 SwiftUI 应用。
- 数据策略：完整知识与复习历史保存在 Mac 本地。
- 远期方向：POC 成立后再评估 iOS、双端同步和商业化。

项目当前只有 Xcode 创建的基础 SwiftUI 工程。本轮只完成产品文档迁入与整理，不把默认界面视为产品实现，也不以编译通过代替真实体验验收。

原始创意记录保留在 [ideas 创意库](https://github.com/RexYoung000/ideas/blob/main/memory-coach.md)，项目内文档是后续需求与实施的依据。
