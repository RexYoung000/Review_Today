## 使用方式

1. 先说明当前要解决的用户问题，再查对应案例机制；不要直接拿外观当方案。
2. 区分录屏观察、官方说明、设计推断和未经验证的效果。
3. 检查平台、用户阶段、必要权限、隐私与商业后果是否相同。
4. 提出具体应用方案并与 Rex 对齐后，才更新项目设计文档或进入实现。

案例媒体仅为用户提供材料的内部研究副本，不是可用于产品、宣传或公开转载的授权资产。对外分享前须另查素材权利与隐私范围。
