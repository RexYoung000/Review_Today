# AirJelly Agent 主窗口结构参考

> 记录日期：2026-09-04  
> 证据：Rex 提供的 AirJelly macOS 主窗口截图；[AirJelly Changelog](https://www.airjelly.ai/changelog) 仅补充其公开描述的会话侧栏、流式、打断和滚动关注点。  
> 证据边界：截图分别证明宽窗口浅色的失败状态和 Agent 起始页可见结构，不证明侧栏收缩、键盘、滚动、流式、辅助功能或恢复行为。

## 可借鉴的结构

- 一条侧栏同时承载产品导航和可滚动会话，不在 Agent 页再增加一条并列会话栏。
- 右侧使用轻量标题、居中内容列和底部锚定输入框，减少整屏卡片嵌套。
- 用户输入、Agent 输出、运行／错误状态位于同一时间线，恢复动作靠近对应状态。
- 会话列表拥有明确的选中状态、搜索和新建入口；侧栏收起后主内容保持完整。

## Review Today 的适配

- 保留今天、Agent、知识库、待处理和系统 Settings；会话跨页面常驻。Agent 起始页含品牌/输入/快捷开始，具体会话才显示历史与底部输入；首次发送才建会话。
- 保留五模式、学习进度、来源、理解状态、知识关系与受控入库，不退化为通用 Agent。
- Agent 输出采用开放内容画布；用户运行详情显示可解释阶段，技术信息仅在开发诊断，不展示隐藏思维链。
- 错误主视图只说明发生了什么、输入是否保留和下一步；底层命令与堆栈只进脱敏开发诊断。
- 保留 Review Today 的品牌角色、Runway 配色与字体；不复制截图的图标、配色或控件外观。

## 明确不采用

- 人物页、人物头像、积分、升级、账户、邀请、反馈、会话文件夹和通用工具入口。
- 持续读取其他 App、主动代办或通用桌面 Agent 权限。
- 在主错误卡中直接显示本机路径、命令、原始堆栈或其他开发者信息。

## 原生验证

实现后必须在 Review Today 的最小、默认和扩大窗口分别检查：侧栏显示／隐藏／拖宽、会话列表滚动和准确选择、Agent 阅读宽度、输入焦点、长内容、运行／失败／恢复状态、浅深主题和 Reduce Motion。只有真实 Mac 操作可证明这些行为成立。
