## 改动与实际行为

同一次意图判断增加学习导航：回顾或推进、当前步骤及本轮连续原话。回到原任务只回顾／补讲时走现有局部回答，不切步骤、不替换待答题。执行端不再只凭 continue 推进：缺失、旧步骤或非当前原话不会取得推进许可，并拦截本批已覆盖的否定／引用冲突；语义识别仍需真实模型复验。明确下一节、既有跳过、整句直接教学和确认后的跨会话续学保留原控制路径；感谢／自述理解不会吞掉同轮明确的下一步请求，也不因此认证掌握。
