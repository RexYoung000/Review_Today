# Jev 对话准确率校准

2026-09-20，独立评测已完成：55 个对话场景、三版合计 165 次真实 Jev 调用、1,430 项原始判断，全部有效且无重试。日常 App、Harness 和模型配置未修改。

**结论：本轮不采用 v2。** 开发集的改进没有在保留验证集延续；仅整理上下文的 v1 值得继续研究，但本轮没有在看完验证结果后改选、调规则或重跑。仍不建议让 Jev 接管完整路由，也没有设置自动接管阈值。

## 验证集差异与下一步方向

| 现象 | 本轮证据 | 影响与推荐 |

| 引用文字影响控制判断 | V011 三版都把被分析句子里的“先别学了”判成当前暂缓，尽管外层明确不执行句中命令 | 后续应明确指令作用范围与被引用材料，保留新样例复验；本轮不增加关键词覆盖来掩盖失败。 |
| 泛化后的转场误报 | v2 在 V008 “取消代办，讲关键帧”上凭空判 clarify_next | 限制下一主题判定的语义范围，不能把每次新问题都视作未指定主题的转场。 |

后续若继续优化，优先保留 v1 的事实整理，仅对知识请求/流程推进、资源代办/资料理解和引用作用范围做单项对照；需要新的未参与调优样例。当前保留验证集已经看过，只能继续当回归集，不能再作为同一轮的独立验收。学习记录筛选和答案诊断的首轮结论未在本批重测或扩大。
