# 淡入可见性修正 · 2026-09-13

Rex 实际反馈上一版没有可见动效。旧版显示层只以 0.16 不透明度覆盖内容，120 ms 结束，变化过弱；上一轮只确认图层触发，不足以判定用户可感知。反馈时运行的是 Xcode 普通 Debug 版，二进制确实包含 PageArrivalFade，系统减少动态为 0，不能归因于旧版本或系统禁用。

本轮维持统一淡入方案，将纸面层起始不透明度改为 0.65，150 ms 内恢复到 0。首帧仍有内容，布局不移动；点击、焦点、连续切换及减少动态规则保持。没有新增每页不同的展开动画。

- [导航、输入、焦点 3 组原生契约](contracts.log) 通过，包含实际 SwiftUI 页面替换、快速中断、点击穿透、窗口失活、减少动态、草稿和中文预输入等既有检查。
