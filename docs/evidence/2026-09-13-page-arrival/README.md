# 四个主页面轻淡入验证 · 2026-09-13

Rex 确认统一短淡入方向后的实现与自测记录。已实现并更新日常签名应用；最终节奏观感待 Rex 验收，既有压力性能问题保持开放。

## 实现

今天、Agent、知识库、待处理共用 120 ms 轻淡入。原生显示层使用当前纸面色，从 0.16 不透明度降至 0，首帧内容可见；不接收点击、焦点或无障碍遍历，不保留旧业务页面、不逐帧刷新 SwiftUI 状态。首次打开、同页更新不重播；快速切换移除旧动画，窗口失活、减少动态直接完成。从其他主页面新建会话时不叠加旧的输入区入场。

## 已验证

- [原生契约](contracts.log)：导航渲染、输入与焦点共 3 组通过；包括真实 SwiftUI 页面替换后的显示层身份、实时减少动态、初始／同页不重播、连续中断、点击穿透、深色与窗口失活；输入组覆盖 12 个场景，包括中文预输入、撤销和草稿。初次测试误写只读系统环境值导致编译失败，改用已有应用级减少动态覆盖后通过，保留 [初次失败](initial-test-compile-failure.log)。
- [签名优化 Debug](debug-build.log) 与 [标准 Release](release-build.log) 构建通过。未改项目默认 Debug 优化等级。日常版本路径、校验值、备份和启动检查见 [安装记录](candidate-build.json)。
- 真实隔离窗口的显示层为 994 × 735；[标准分支](surface-standard.json) 280 次观察均在前台，四页均观察到 opacity 从约 0.16 降到 0；[减少动态分支](surface-reduced.json) 同样 280 次均为 0 且无动画。减少动态使用项目已有应用内覆盖，未改系统偏好。
- 日常应用经访达正常启动：原有 3 会话、8 知识仍可见；8 次主页面切换到正确选中项；未发送中文草稿在知识库与 Agent 往返后保留，检查后清空；本地服务健康，无模型请求。隔离 QA 已退出。

## 性能边界与体验验收

[普通数据采样](navigation-small.json)：排除开头共 2 条预热记录后，每方向 30 次，全部前台，页面绘制 P95 今天 83.6 ms／Agent 65.6 ms，首次反馈 P95 83.7 ms／65.6 ms。计时为导航处理到首次 AppKit 绘制，不含 OS 输入派发、完整可操作时间或淡入结束；不能与物理屏幕帧等同。此轮没有重新做压力数据全验收，上一轮超目标项继续见 [性能健康记录](../2026-09-13-performance-health/README.md)。

Rex 可在已更新的日常应用中依次切换今天 → Agent → 知识库 → 待处理，再快速反向切换：选中应立即跟随、页面仅有轻微淡入、无滑动或逐卡排队；进入 Agent 后可立即输入，切走返回保留草稿。最终节奏是否合适、持续自由操作与压力场景的卡顿仍需分别验收。本次不关闭 M1 或执行发布。
