## 实现范围

新增 `tools/repair-legacy-deletion-lifecycle.py` 和固定清单 `tools/legacy-deletion-lifecycle-scope.json`，仅 Python 标准库，不接入 App 启动或修改原生／服务删除代码。清单只有已核验的第 4–6 条记录，工具固定其 SHA-256；默认只检查，`--apply` 才执行，当前只接受指定 `.noindex` 临时目录或本批 `output` 隔离副本，不支持日常目录或临时扩大对象。

同时匹配固定旧备份指纹及已归档／版本 0、原生完整删除队列与三条原动作身份／版本、目标本机实体已不存在、后台原快照及两个生命周期字段都缺失。已有删除回执、字段已存在、ID／内容不符、链接输入或范围清单变化均拒绝。仅补 `status=archived` 和 `lifecycle_revision=0`，保留所有正文及其他字段，不修改删除标记、不发送删除请求。

执行前用 SQLite backup API 保存三份一致副本；事务取得写锁后重新核对，三条同事务更新并检查完整后台表仅发生预期变化，失败全部回滚。成功后新连接读回并记录结果；有匹配回执的重复执行返回 `already_applied`／写入 0。提交后如回执写入失败，明确报告 `committed_review_required` 并停止，不能谎报回滚或自动再写。
