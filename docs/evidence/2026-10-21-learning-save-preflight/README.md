## 守卫验证范围

| 场景 | 结果 |
|---|---|
| pending、HOLD、越界的批准参数 | 阻止安装，原文件不变 |

| 预留后撤销授权 | 在传输前拦截 |
| 网页失败、备用供应商、连续读取 | 逐次计数，16 次后拦截第 17 次，同时关闭模型额度 |

本地日志及案例结果见 [preflight.log](preflight.log)和 [preflight-result.json](preflight-result.json)。11 项为独立子进程案例数，表中部分案例合并展示。

[quota.py](quota.py)只供本批 QA 使用：文件锁保护跨线程／进程计数；先保守占额，再以程序身份关联实际 SDK 发送；关闭 SDK 隐式重试；超时仍占额，回包用量可在到限后补记。任何一维到限即停止接纳新操作，已预留的操作可结束；手动 STOP／HOLD 或撤销授权也会拦截已预留而未发出的操作。计数上限不是费用上限。

网页按供应商搜索／正文／上下文工具的每次调用计数，失败及备用各计一次；浏览器正文若启用也按一次操作计入。不是按 HTTP 握手、图片或页面子资源计数。离线案例没有连接真实供应商、MCP 或浏览器，不能据此报告真实供应商联调通过。
