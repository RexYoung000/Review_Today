# 玻璃预选、小结入口与次级页面复修

状态：独立原生原型已更新，构建与定向检查完成；待 Rex 视觉／交互体验确认。日常 App、后端、正式评分和模型配置没有改动。

## 直接体验

打开 `output/today-review-prototype/TodayReviewPrototype.app`（Review Today · 交互原型）。

- 今天右上角 **小结预览**：无需先答完一轮，独立示例不改当前进度。顶部可切换部分／全部完成，**重播动作** 可再次查看 Mr. B；⌘4 也可打开。
- 今天 **开始学习／模拟考**：玻璃保持通透，指针停留期间循环扫光与沿边移动的光点，不播放声音。⌘3 是光效的受控展示，依次开启两个入口、关闭展示；它不是自动化鼠标悬停操作。
- **模拟考**：并列知识测验／模拟面试，选择后说明区更新；仍不执行考试。
- **最近学习**：三条记录可展开为五条，点击对应话题进入摘记与下一步，知识摘记可实际打开、关闭。
- **准备复习**：本轮范围、目标选择与固定开始区；全部到期默认，时长／数量可调，语音与文字开始保留。
