### 验证中修正的问题

1. 首次真实回放发现“稍后录入”后又询问新会话。现有继续操作已表达留在本会话，修正边界后重新真实回放，确认实际输出下一段。
2. 首次原生 QA 包漏带 `MrBMotion.html`，验证了资源失败降级；补齐资源、重启验证包后播放正常。日常 Xcode 包已有该资源。
3. 录入原来套用发消息滚动，导致面板移出视区。修正为保留输入焦点，将当前面板置于可读位置；移除重复入库任务块，复录通过。
4. 新增保存回执等待期间的会话事件同步，避免本机已保存但续讲事件没有拉取；重开界面优先显示本机已持久化结果。
5. 补上恢复时的版本连续性，以及自然语言显式保存后不再次邀请同一回答。
6. 后续 QA 录屏辅助调用曾卡住 UI，停止隔离进程并把录屏启动移到后台。未把这次失败录屏作为通过证据；保留此前成功完整录制，最终窄窗口/减少动态/跳过检查用真实窗口复核。
