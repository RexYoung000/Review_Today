# Voxtral 3 与现有语音方案隔离 POC

2026-10-21，Rex 授权比较中文转写、播报、延迟与打断，暂不切换日常配置。本文先冻结比较方法，实际结果随后追加，不将准备完成写成实测完成。

## 范围与隔离

- 现有侧复用生产 `agent_voice` 音频桥和阿里云实时配置；候选侧仅调用 Mistral 实时转写和独立 TTS。当前普通听写的 Fun-ASR 不在本次连续语音对比内。
- 只用 macOS Tingting 合成的非敏感中文音频，同一 WAV、相同实时发送节奏。无真实麦克风、扬声器、日常会话、知识卡或学习数据；不启动日常服务、不调用文字 Agent。
- 导入生产模块前设置临时 Harness／Review 数据库，随机本机端口；密钥只从既有 ASR 配置和独立 `providers/voxtral/.env` 读取，不输出密钥或供应商请求头。
- 合成输入、生成音频与原始数值留在被 Git 忽略的 `output/voxtral-voice-poc-20261021/`，便于本机试听；提交目录只保存脚本、方法和脱敏报告。不创建或克隆云端声音。
- 本批每家最多 16 次供应商操作，含连接、音色查询、失败和取消；每家输入最多 150 秒、TTS 最多 1,200 字符。无自动重试，不占用或恢复其他学习／网页实验的冻结额度。

## 比较内容与口径

1. 中文陈述、中英术语、数字、否定、改口与句中停顿；转写同时保留原文、实际输出、规范化 CER 和关键字差异。CER 只衡量转写差异，不替代含义复核。
2. 同文中文播报：首个可播放 PCM 到达、完整生成、音频时长、实际音色；保留试听文件，发音与自然度由人听判，不用另一个转写模型冒充听感。
3. 分开记录连接、最后输入采样到完整转写、提交到转写、请求到首个可播放音频。输入按音频原速发送，不沿用旧脚本加速上传的计时。文字 Agent 不参与，不能宣称完整聊天端到端延迟。
4. 分别验证首次可播放音频之后的播放队列打断，以及观测到真实上游 PCM、音频尚未放行时的生成中取消。使用按真实采样时间消耗的无声播放队列，记录触发时点、清队列、晚到旧音频、取消任务结束与新句恢复。它只验证传输／队列层，不证明真实麦克风抢话、声学回声消除或扬声器停止时间，也不将 HTTP 关闭／本地任务取消当作供应商取消 ACK。
5. Mistral 的句末事件可能先于尾部转写：等待流式延迟后再形成完整句。记录停顿时的提前结束和改口残留，不调用保存／评分工具。

本轮只比较拆分语音层，不引入完整 Voice Agent API。若缺少密钥、中文音色或接口权限，仅暂停依赖项并保存阻塞，不以旧版 Voxtral、英文音色或模拟结果替代。

### 现有侧实测

使用当前 `qwen3.8-omni-flash-realtime`／Tina 和实际生产 `agent_voice` 桥，分两次隔离连接执行。六份输入共 35.38 秒，另添加相同的 1.65 秒尾部停顿，每次按原速发送。基线通过手动提交模拟当前停顿策略，没有执行原生 VAD；句中 1.1 秒暂停不会因此被本工具切成两次提交。

| 样本 | 实际转写差异 | 提交后完整转写 | 最后有效语音采样后完整转写 |
|---|---|---|---|
| 中文陈述 | 忽略标点后相同 | 218 ms | 1,969 ms |
| 中英术语 | `RAG` → `Web` | 222 ms | 1,973 ms |
| 数字与日期 | 忽略标点后相同 | 235 ms | 1,987 ms |
| 否定 | 两处「不要」保留 | 201 ms | 1,952 ms |
| 改口 | 「明天，不对，是后天下午」保留 | 207 ms | 1,958 ms |
| 句中暂停 | 内容完整，断句标点变化 | 202 ms | 1,953 ms |

提交后中位 212.5 ms；从最后有效语音采样计约 1.96 秒，主要包含既有停顿。有效语音位置由合成 WAV 音量窗估计，非人工语音标注。这里比较的是脚本与转写；合成器对 RAG 的发音尚未人工试听，不能归因成真实用户普遍识别错误或稳定准确率。

| 照稿播报 | 结果 | 首个可播放 PCM | 生成音频时长 |
|---|---|---|---|
| 中文概念 | 既有文字一致性守卫拦截，未放行音频 | 不可用 | 不可用 |
| 中英术语与数字 | 放行 | 2,040 ms | 10.08 s |
| 否定与操作边界 | 放行 | 1,839 ms | 6.72 s |

拦截结果原样保留，不放松守卫或用重跑成功覆盖；该次未保留上游改写原文，无法判断具体哪个词导致拦截。首 PCM 到达不等于真实扬声器已经发声；未包含文字 Agent 生成、原生分句和真实设备缓冲。

打断分项：

- 播放队列：长句首 PCM 等待 4,648 ms，收到后 600 ms 打断，清除约 25.878 秒待播队列，旧 PCM 后续接收 0，新句首 PCM 1,025 ms。此时供应商生成已经完成，只验证本地止播。
- 生成中：隔离进程只读观测到上游真实 PCM 后约 760 ms 触发取消，放行给客户端的音频仍为 0，旧音频后续放行 0；新句首 PCM 919 ms。生产匹配／放行逻辑保持。取消任务在本机不足 1 ms 结束，但没有远端取消 ACK，不能据此承诺云端已停止或不再计费。
- 两次真实流程都没有收到晚到旧 PCM，因此强制晚到丢弃只由离线测试覆盖。没有测试真实外放回声、真人开口检测、麦克风或扬声器停止时间。

现有侧账本为 15／16 操作：两次连接、六次转写、七次生成（包括拦截和取消），不是十五次文字模型请求；余 1 不自动使用。音频／字符上限未触及，实际金额和账户账单未核。

### 续接

在 `agent-service` 目录，配置好独立 Key 后运行：

```sh
.venv/bin/python -m tests.voice_provider_poc --live --provider voxtral
```

该命令复用已保存的六份 WAV，先查实际中文预置音色，再测试固定 Voxtral 3 实时转写和 TTS；不自动切换版本、不克隆声音或选择英文声音兜底。缺少中文音色只暂停播报依赖项，保留转写观测。旧现有侧报告不会重跑，候选仍受同一账本 16 次上限约束，失败阶段不自动重试；完成后需增量整理双方数值与试听结论。异时运行需区分网络／时段影响，不直接把全部差异归因于模型。

仅准备样本、不联网：`.venv/bin/python -m tests.voice_provider_poc`。离线验证：`.venv/bin/python -m pytest tests/test_voice_provider_poc.py -q`。真实数据的取消分项来自当时脚本；后续文件命名和脱敏错误记录修订经离线检查，未再次付费复跑。
