## 同一模型生成的实际差别

预先选 Python、新接口、Swift 三题；全部使用现用 COACH_MODEL（请求 `deepseek-v4-flash`、供应商报告 `deepseek-flash`）、同一提示、smart 对应的无推理设置、同一来源选段规则。模型不收到“资料来自哪家服务”的标签。每项最多一次生成，无探测、格式修复或重试。

| 固定问题 | Exa 提供的资料 | Tavily 提供的资料 | DeepSeek 提供的资料 |
|---|---|---|---|
| Python 列表 | 正确给出嵌套与展开示例，解释 None | 明确说材料是 deque／array，无法确认 list；给了注明类型的 deque 示意 | 能解释并给正确示例，同时明确提示证据为 Python 2 |
| Search／Fetch | 明确说明现有模型价格／发布资料不足，未冒充新接口规则 | 功能、按成功请求计费、摘要与正文区别齐全；字段罗列较长 | 同样覆盖核心事实，区分中文人民币／英文美元来源，没有自行换算 |
| Swift 取消 | 正确解释协作取消、状态检查和清理，排除不相关测试页 | 没有正文，按预定规则跳过生成 | 正确解释取消标志、检查点和退出方式 |

实际 **8 次生成成功、1 项无正文跳过**；八份回答的引用列表均限于提供的来源。人工未发现明显核心事实矛盾，但有两份回答未解决主要问题、另有旧版本证据限制，不能把 JSON 成功当内容合格。逐项标准及判断见 [review.json](review.json)；没有独立盲评或跨轮统计，不合并成模型胜率。

**差异主要来自拿到了什么正文。** Tavily 的正确 Python 文档在第三条，因固定前两条的测试方法未进入生成；正式 Harness 选材模型若选择第三条，可能获得更好的输入。本实验没有调用正式选材、意图路由或入库流程，不能据此断言日常回答一定同样失败。稳定基础知识原本可直接教学，本次为检索链比较而额外施加了“只按给定证据作答”约束。

完整原始生成内容及每次具体缺口保存在本机忽略提交的 `output/web-quality-2026-10-18/answers.md`；`results.json` 保存原输出及用量，`captures.json` 保存实际正文、片段及生成输入。公开 [results.json](results.json)保留 URL／标题、来源选段范围、原始输入／输出摘要哈希、状态与用量，不复制长正文及回答；这些本机文件不是远端仓库附件。
