## 改动与边界

普通题不再只信 `passed`。在原同一次评分中增加 `answer_coverage`，列出题面明确要求、是否答到及当前答案的连续原文。程序只接受题面和答案中能定位的依据；缺项、否定项、空依据或重复项目不能支持整题通过，也不会记录整个概念绑定或形成通过后的知识邀请。保留部分正确反馈和有效补充题。

题面没问的整节要求不追加为门槛，同义表达仍由原评分理解。讲义、反馈、题面不能替用户作答；错误引文沿现有一次有界结构修复，缺少评分依据不等于用户答错。没有额外独立核验调用。主动保存、综合题、提示、停止、版本及旧记录保持；实验评分继续使用出题前冻结的逐项标准，由程序计算通过，不让反馈模型重复裁决。

这仍依赖模型正确枚举题面要求并判断语义；程序核对结构、否定结论与引文，不能证明模型绝不会漏列必要项或误解自然语言。没有扩展为通用评分治理，也没有更换模型、供应商或界面。
