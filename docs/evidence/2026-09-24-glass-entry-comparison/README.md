# 玻璃入口原生对照 · 2026-09-24

这是独立合成数据原型中的视觉对照，正式 App 入口保持原样。启动 `output/today-review-prototype/TodayReviewPrototype.app` 后会直接打开「入口玻璃 · 原生对照」；关闭后可通过「原型 → 打开玻璃入口对照」或 ⌘5 再打开。左侧为当前循环扫光，右侧为 B 合成试作：原生 regular 玻璃、随指针定位的中性银白反光、局部内缘折光。两个入口均为实际 84pt 高的原型尺寸，点击仅显示模拟反馈。

可在入口上移动指针，也可使用「定点预选」的左缘／中部／右缘直接比较光的位置；该控制只服务于原型，不进入产品。右上角切换浅深色与减少动态；⌘9 可检查最小窗口的上下排列，⌘0 恢复默认尺寸。

证据：[浅色定点预选](light.png)、[深色定点预选](dark.png)、[原速对照录像](interaction.mp4)。录像来自本原型窗口的 ScreenCaptureKit，约 30.8 秒、1160×592、目标 30 fps，不含音频；视频以定点预选和主题切换展示可重复状态，不代表自由鼠标运动的手感测试。

已验证：原生构建、两个入口的尺寸与点击反馈、浅深色、定点预选位置变化、减少动态的静态状态、最小窗口重排。试作没有深色蒙层、黑色外框或彩虹色；文字与图标不参与折射。真实自由指针的连续跟随手感、系统级减少透明度及 VoiceOver 完整流程仍待人工体验，不能以定点切换录像代替。当前版本等待 Rex 选择或提出修改意见，再决定是否替换正式 App。
