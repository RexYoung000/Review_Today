用户两轮反馈纯淡入没有感觉后，确认推荐的统一轻抬入：内容从下方 8pt 回到原位，同时淡入，180 ms 完成。侧栏固定；不引入逐卡排队、缩放或各页不同动画。已实现并更新日常应用，最终节奏待 Rex 验收。

## 实现与验证

现有页面外层使用局部显示位移，复用淡入显示层；不改变布局尺寸、不保留旧业务页面。页面身份变化才触发；待启动任务在新切换、减少动态、失活和卸载时取消。快速连续切页直接呈现最后选择，输入不等待动画。

- [普通 Debug 构建](debug-build.log) 通过，保持项目默认 -Onone；[导航／输入／焦点 3 组原生契约](contracts.log) 通过，包括真实 SwiftUI 页面替换后的显示层、即时点击、连续中断、减少动态、中文预输入、撤销与草稿回归。
- [浅色原速](light.mp4)、[深色原速](dark.mp4)、[减少动态原速](reduced.mp4) 使用原生生产页面、程序导航和独立数据，含四页往返及每 40 ms 一次的连续反向。只录制自身窗口，无桌面、声音和模型请求，保持原始时间戳。三段完整解码无错误，见 [检查数据](checks.json)。
- 连续帧实看确认移动与淡入并行。同一 Today 标题从录像 y57 → 56 → 55 → 54 → 51 → 50 → 49，恢复稳定，见 [像素轨迹](title-motion.json)。减少动态对应标题保持 y49，显示层 opacity 恒为 0。像素轨迹用于验证显示移动，不能推导 OS 输入延迟或恒定帧率。
- 日常 App 经正常退出、备份、同签名替换，再从新访达窗口的精确应用路径启动。旧访达窗口曾保留重命名前条目：显示名称为 App，但 URL 指向备份；本轮发现后没有打开该条目，另开窗口确认正确 URL。最终运行进程和实际动态库校验一致，见 [安装记录](installed.json)。
- 日常原有 3 会话、8 知识可见，7 次切页到正确目标；未发送中文草稿切到知识库再返回 Agent 后保留，检查后已清空。隔离 QA 已退出。

本轮没有重跑 Release、压力数据或完整可操作延迟；不能用动效证明之前的卡顿已解决，也不能以自测代替用户节奏验收。窗口缩放与 VoiceOver 未在本轮重跑。

试用入口：日常应用中今天 → Agent → 知识库 → 待处理，再快速反向。应看到内容轻微上移并恢复清晰，侧栏固定、最后选择立即生效；进入 Agent 后可直接输入，切页返回保留草稿。
