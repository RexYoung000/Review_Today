# 教学、检查题与判题依据对齐

日期：2026-10-03。范围来自最新「直接教我 RAG」实际对话的只读检查；按 Rex 的「开始修复」授权实施。规范先以 `a241def` 独立提交并推送。日常历史不改写，M1 总体验收保持开放。

## 改动

- 首轮先定义概念或给直观例子，再给紧凑地图并讲当前一步。题目限于当前实际讲过的内容，后续目录不算已经教学。
- 日常判题携带实际讲解、题目、用户答案与当前步骤身份。问题攻克同时保留原参考及后续补讲。缺依据时不调用判题、不升级掌握，并将动作改为补讲／继续。
- 新计划分别保存 `step_conditions`，全局 `success_check` 不再复制给每步。旧缓存兼容，不批量修改旧记录；旧占位条件不进入教学目标投影。条件变化计版本，原步骤 ID、消息与掌握证据保留。
- 整节完成条件用于安排教学，不作为一道小题的评分标准，不传给日常判题。正确性与完整性围绕题目实际要求。
- 正文尾部独立「想一想」若漏填题目字段，可原文提取并绑定当前讲解，最终只展示一次。普通行文、多段、多标记、围栏与缩进代码不作题目提取；非教学回复不处理。
- 续学明确传入推进后的当前步骤。入口明确允许非攻克课程在检查未答或未通过时继续，不把继续误判为追问或强制先答旧题。继续／跳过不证明掌握。
- 针对真实遇到的整体标准漏填、条件数组错位，补明确的格式恢复说明；保留原来的一次恢复及执行预算，没有增加日常 Jev 调用。
