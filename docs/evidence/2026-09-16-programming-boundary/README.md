# A005 编程学习与开发交付边界 · 2026-09-16

## 问题与实现

Rex 在日常 Agent 询问“你能帮我 coding 嘛”，回答承诺写代码、排查、重构和按需求实现。产品原本是学习教练；实际工具没有项目读写/执行能力。意图层有宽泛能力限制，回答层缺少开发交付边界，流程也没有独立分流。

- 能力询问/纯开发交付：生成正文、创建任务和知识收尾前，Harness 发布明确的范围说明。五种模式都不能转成开发任务。
- 学习编程：代码解释、报错原理、局部教学示例正常回答。中文/英文、否定、引用依据语义识别，不用关键词禁用编程主题。
- 混合请求：意图层给出原文学习片段；Harness 校验并隔离片段，只讲学习部分并说明不能执行开发。无有效片段不进入自由生成；原学习任务/来源不污染，超时重试仍解释相同片段。
- 正文讲解、问题攻克和资料学习共享能力边界。旧检查点可解析，缺少新边界字段的意图重新识别；历史回复不重写。
- 产品规则见 `product-requirements.md` 与 `agent-harness-v2.md`；统一案例入口为 `agent-iteration.md` A005。

## 分层验证

- 失败先行：[旧实现受控结果](controlled-before.txt)。能力询问直接泄出通用开发承诺，五模式开发请求创建任务，已有学习状态被推进；新增字段缺失也是预期红灯的一部分。首次命令因工作目录错误未收集测试，纠正目录后才取得本结果。
- 最终服务全量：319 项测试、34 个子测试通过，见 [结果](controlled-final.txt)。覆盖 A005 原句、五模式开发拦截、教学放行、引用/否定、停止/暂缓、旧缓存、稍后录入保留、混合片段校验与失败重试、旧学习任务不污染。仍有两项已有 FastAPI 弃用警告。
- 真实模型：14 个合成语义样本 + 4 条隔离完整 Harness 回放。最终分类全部符合预期；原问句简短说明学习能力，仓库修改请求不创建任务，教学示例正常生成，混合请求解释闭包且明确不部署。[最终回放](real-model-final.log)。未写日常会话/知识库。
- 初轮完整回放出现混合误拦：单独路由给 none，但完整链路重新识别成开发交付，吞掉闭包解释。旧脚本末尾 PASS 只覆盖粗粒度完成状态，不能证明混合行为正确；人工复核发现后新增 mixed_learning 与逐字学习片段，并加强完整链路的预期分类断言。[保留初轮记录](real-model-initial.log)。
- 额外发现：教学样本对“十行”的遵循和讲解篇幅仍不稳定，初轮还套用了面试结构；此处只验证学习没有被拦，不将教学质量整体报告为通过。该现象作为待对齐候选留档，本轮未扩大为课程风格重构。
- 本轮仅服务逻辑/提示词与文档改动，无 SwiftUI/动画/schema 迁移；未重跑 Mac 构建和原生视觉验收，不借用旧测试结果。真实模型样本是定向检查，不代表统计准确率。

## 复跑与体验

- 受控：仓库根目录 `bash agent-service/run-controlled.sh`。本机沿用 `/tmp/review-today-topic-test-deps-20260915` 的 pytest，以 PYTHONPATH 提供；未修改产品依赖或凭证。
- 真实调用：`cd agent-service` 后执行 `.venv/bin/python -m tests.programming_boundary_real_smoke --live`；脚本使用独立临时数据库和固定合成样本，调用现有模型配置，不执行知识保存。
- Rex 验收：Agent 发送“你能帮我 coding 嘛”应只说明学习范围；“帮我改仓库跑测试”不承诺执行；“用一个 Python 例子讲循环”仍有教学；“先解释闭包，再帮我部署”应解释闭包并明确不能部署。
- 日常 App 所属服务在确认无执行中/排队任务后通过原监控机制重启加载代码；healthz 为 ok，router/coach/risk 全部 ready，见 [运行健康状态](runtime-health.json)。原生 App 未退出，未向日常聊天发送测试消息。普通提交与推送随本轮交付；最终措辞与自然语言覆盖仍待 Rex 验收。


## Rex 体验复修：能力介绍仍像 coding 助手

2026-09-16，Rex 要求改为“帮助理解 coding 相关的知识”。首版固定文案虽然收住了开发执行承诺，但仍列读代码/报错/调试等服务清单并主动追问，定位表达未通过用户体验验收。

现改为：“我是 Review Today 学习教练，可以帮助你理解 coding 相关的知识，比如编程概念、代码逻辑和背后的原理。”同步能力介绍提示词；明确开发交付请求的分流保持不变。

本次增量验证：11 项相关测试、9 个子测试通过（[结果](wording-controlled.txt)）；以截图原句“你有 coding 的能力吗”运行一次隔离真实模型完整服务回放，返回新文案、不创建任务或录入（[回放](wording-live.log)）。本次没有重复上一版全量/14 个样本或原生视觉检查。日常服务在空闲时重启加载，最终文案仍待 Rex 验收。
