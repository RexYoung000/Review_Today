# 问答证据与知识卡生成闭环

2026-10-03，依据 Rex 的「开始修复，记得还有检查是不是漏了相关知识卡片生成的步骤说明」实施。修复来自真实 RAG 对话的审查，不改写旧聊天、旧掌握记录或现有知识卡；M1 总体验收保持开放。

## 修复与生成步骤

- 保存状态改为读取当前讲解、整理稿、录入任务和本机确认；引用历史卡片不能证明本轮已保存。查询会说明尚未整理、待确认、生成中、成功或失败；成功后列出这次实际卡片标题。
- 答题后的有效解释和纠正纳入本段来源。明确收尾、直接要求保存使用同一来源收集；用户原始错答、其他任务、旧计划、失效运行和重试旧版本不作为知识事实。状态询问和题意澄清不阻断后续保存。
- 每道新检查题提前关联实际讲解、步骤、知识点和来源摘录；小题通过只验证相应知识点，不自动完成整节。旧题缺乏可靠关联时只给反馈，不追认掌握。题目有歧义时接受合理条件回答或说明题面不足，不强迫唯一预想答案。
- 「不理解你的问题」保留原题与学习进度，只澄清题意。正文末尾重复的检查题安全去重；无法验证的新题利用既有一次结构恢复，不无限重试。
- 问题攻克仍要求独立作答和迁移检查；首次待确认稿保留参考答案并纳入有效反馈，已经交付的稿不在保存时偷偷重写。

知识卡不是每次答对就自动生成。实际路径为：**讲解与作答留在学习记录 → 用户明确收尾后选择「录入知识」，或直接要求整理保存 → 按确认的本段内容生成卡片、复习问题和评分依据 → 校验与必要核验 → 本机写入并确认成功**。本次补的是此前缺失的流程说明、来源覆盖和状态真实性，原卡片生成管线已存在。

每个学习任务首次有效检查通过后，用一句话说明该流程；后续不重复催保存。用户问「有没有记录／怎么生成」时说明当前阶段和下一步。纯询问与保存动作若被模型同时输出，结构校验要求重新依据原话判断，持续矛盾则不执行写入。

旧题反馈不能可靠关联讲解时，面板及状态答复说明暂只整理已确认讲解，避免暗示旧纠正已经全部覆盖。历史错误进度保留，不做批量猜测修正。

## 验证

全量受控回归 **980 passed、4 skipped、406 subtests passed**，5 条既有弃用警告，见[最终日志](controlled-final.log)。此前 955 项／394 子测试的[初轮日志](controlled-initial.log)保留；后续按真实失败和终审发现补齐断言。最终生成规则还通过既有 capture／quality 检查 34 项／12 子测试。所有受控回归使用隔离库和空供应商凭据。

真实模型使用当前 DeepSeek 配置、Jev off 和临时合成会话；不读取日常聊天，不开放网页工具。卡片生成调用真实 `run_capture`，保存验证使用临时 SQLite 客户端，事务写入后重新打开核对全部字段，再发送模拟 Mac ACK。它验证服务生成与提交协议，不代替原生 SwiftData／界面验收。

[D](live-d.jsonl.gz) 完整九步结构通过，实际反馈能接受条件回答，只记录被检查的两个知识点；首次通过及查询状态均说明生成步骤，收尾来源包含讲解与有效反馈。但首次生成的 6 张卡把同概念的定义／边界拆开，例子单独要求背诵，部分变体与共同评分范围不一致，因此[卡片语义复核不通过](live-d-review.json)。

按已有完整概念契约加强整理和独立语义校验后，[E](capture-e.jsonl.gz) 只重放 **D 同一份冻结来源**，没有重打教学，生成「关键词检索」「向量检索」「两种检索对比」3 张卡。定义、机制和限定回到同一卡；例子不再独立背诵；只保留覆盖本卡范围的主问题。生成→临时客户端回读／ACK→状态查询三步通过，[本批关注项的内容复核通过](capture-e-review.json)，[实际卡片正文](cards-e.md)可直接阅读。两张概念卡和对比卡仍有内容重叠；评分依据短摘录未逐条审计全部限定，真实复习判题和原生持久化也未在本次重跑，不能据此宣布整个知识与复习质量验收完成。

[歧义输出的离线复核](ambiguity-a-review.json)同时将原模型结果放回 concept／step 两种临时状态，核实均未升级整节或生成草稿。全部真实验证共 **27 次语义模型调用、210,548 tokens（其中缓存 125,568）**；不含启动能力探测，不估算金额，见[逐批用量](usage-summary.json)。gzip 原始报告无损保留全部模型输入、输出、状态与失败，均为合成材料。

Agent → 原聊天或新学习会话。可依次体验：

1. 回答当前小题，反馈只评价本题所问；首次通过时说明知识卡尚未入库。
2. 输入「刚才回答的知识点有没有记录成知识卡？要怎么生成？」查看真实状态与步骤，学习进度保持。
3. 输入「这一段可以收尾」，选择「录入知识」；也可直接说「把刚才内容整理成知识卡」。
4. 保存完成后在知识库查看本段知识点、解释和有效纠正。旧卡不会自动改写，新卡只有本机保存成功后才报告成功。
