# 边界回复的上下文承接

本次修复保留产品范围与实际执行守卫，让范围回应承接具体请求及前文。已有用户聊天只读核对，模型重放全部使用合成对话和独立临时数据库；没有把真实的情绪／求职聊天送入实验或写入本报告。

## 改动与验证

- 纯范围回复优先采用入口 LLM 的有效回答，记录 `entry`／`regenerated`／`fallback` 和原因。空、过长、代码／链接、明显交付承诺、身份重述及已讲过的替代建议触发表达重做；生成失败才使用简短保底。检查是有限防护，不能证明每种自然语言都符合要求。
- LLM 的 `reply_purpose` 区分产品信息和对刚才限制的确认；程序核对真实前文及独立请求，避免 `question` 标签把确认重新送入讲解。Jev 不覆盖这一职责。当前对话策略为 `dialogue-context-3`，Jev 局部入口仍为 `jev-entry-3`。
- 模型问题使用程序提供的配置名；嫌建议麻烦时简短承接并停止加建议。混合请求的独立学习摘录和用户明确的句数约束分开保留。
- [最终完整回归](controlled-act-final.txt)：764 tests / 331 subtests 通过。覆盖关闭／开启 Jev 的既有路径、范围与控制优先级、重复确认、混合知识请求、任务／保存保护、生成失败、取消／迟到、预算和旧记录兼容。
- [三组原生契约](native-contracts.txt)通过：AppRuntime、AgentServiceMonitor、ConversationReplay。仅修改后端和文档，复用已有 Debug 原生构建；测试 App 在空闲时重启后端，供应商、凭证来源、日常开关、正式复习和排期未改。

最终 [live-v5.jsonl](live-v5.jsonl) 的 20 轮（基线／Jev 各 10 轮）通过本批结构及路由检查。案例包含首次问候、模型信息、SVG 交付与连续两次确认、混合知识请求、学习建议与拒绝、资源获取与追问。合成材料相同，各组沿用自己实际生成的前文；完整提示词、输入输出、判断和调用账本均保留。

人工复核：最终两组的连续确认均直接回答刚才的交付限制，没有重新自我介绍或重复教学能力；“不想这么麻烦”分别为“好，那套建议先放下，不折腾了。”和“好，那就不折腾这些了，刚才的建议先放下。”。混合知识解释保留句数约束，无成品交付、任务或保存。Jev 的模型信息回复仍附带不必要的网关／权重说明；原生首轮范围回应仍偶尔附带学习邀请。这些是保留的表达局限，不将本批 20 轮通过表述为日常准确率或所有语言风格已达标。

## 原始失败与修正

所有旧文件保持原样，新一轮使用新文件：

| 文件 | 原自动结果 | 发现与处理 |
|---|---|---|
| live-v1.jsonl | 15/20 | 模型问题的短回复被普通问答覆盖；混合摘录不合法、句数丢失；限制与替代建议仍重复。两项 activity 断言过严：普通学习建议和合法知识回答可记录 knowledge_answer；后续明确排除这两类，原结果不改。 |
| live-v2.jsonl | 19/20 | 混合摘录将不连续片段拼接，生成转入保底；合法摘录又丢掉一句话要求。分开保存句数，仍须连续原文摘录。 |
| live-v3.jsonl | 19/20 | 模型名答对，但 capabilities＋question 仍多走讲解。资源追问还会重说替代建议。 |
| live-v4.jsonl | 20/20 | 自动检查通过，但原生第二次确认再次变成普通问答，说明离线检查不足以代替真实界面复验。 |
| native-v1.json | 第三轮失败 | 保留原生合成会话。新增明确对话动作与真实前文核对，补针对性回归。 |
| live-v5.jsonl | 20/20 | 最终修订复验，不覆盖早期语义失败。 |

五轮开发实验共 100 个回合、205 次 HTTP 请求（Jev 50 次），已知费用 0.054873–0.105378 USD，用量无缺失；原生检查另计。早期混合知识讲解还出现篇幅和知识措辞问题，均保留原输出，不作为本次知识准确性验收。

费用与次数可重算：在仓库根目录运行 `agent-service/.venv/bin/python docs/evidence/2026-09-22-contextual-boundary-replies/summarize.py`，结果见 [summary.json](summary.json)。真实回放入口为 `agent-service/tests/contextual_scope_real_smoke.py --live --output 新路径.jsonl`，使用既有凭证来源，拒绝覆盖结果文件。
