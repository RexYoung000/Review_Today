## 修复与复核

先前隔离检查中，一份 8,132 字符的公开资料在字符 7,000 处包含所需事实；核验输入有该事实，回答输入却只保留首 4,000 字符。正文仍存在，缺口发生在请求投影。

本次改为每页一个连续窗口，用本地中英文词项重合度选择，优先保留命中处及邻近上下文。每页最多 4,000、同一轮公开来源合计最多 12,000 字符；用户材料不参与这个预算。来源身份、版本、正文哈希、原文字符区间、原因和省略量随运行记录保存；无匹配明确首部回退。

- 核验、材料充分性检查、普通回答、教学、JD 分析、问题攻克和 Jev 使用同一轮冻结的来源片段；后续阶段新增来源只使用剩余预算。
- 读取器已交付的正文仍用于持久化与知识保存，不改为节选；读取器本身现有 20,000 字符默认上限保持，不宣称读到网页原始全文。
- 新问题／补充输入重选。旧核验缺少版本／正文哈希／范围绑定或对应片段变化时，当前证据降为未核验。显式证据和任务上下文中的证据保持一致。
- 同一输入的失败重试和快照恢复沿用原查询与片段，即使运行 revision 变化；新增输入才改变输入签名。
- 刷新后的来源按版本合并，防止较旧材料缓存覆盖刚核验的新正文；重复来源去重并计入实际预算。来源没进入本轮输入时，不把它列作本轮回答的支持性引用。

## 当前限制与使用

本地词项重合度不等于语义理解，不保证同义词、跨语言或多处相隔很远的事实都被同一连续窗口覆盖；窗口可能截在句中，元数据保留精确范围。无匹配时仅为首部回退，不能被当作相关性／事实正确证明。省略范围仍须服从核验结果，不额外增加模型调用解决选段。
