# A012 首次问候的有效介绍（2026-09-21）

状态：已实现、完成原生自测并加载到当前 Jev 测试 App，待 Rex 体验验收。日常 Jev 开关、供应商及复习规则未变。

## 变更与实际体验

此前修复将“不要反复介绍身份”扩大为所有问候都禁止介绍；提示词和短答过滤共同删掉有用引导。按 Rex 确认，当前会话尚未介绍时，首次纯问候应说明是谁、能帮助什么、如何开始；介绍过后结合前文接话，明确询问能力时仍正常回答，问候附带知识或操作时优先真实请求。

仍复用入口同次短答，没有新增欢迎模板、模型调用或会话状态字段。保留有用的身份说明；纯反馈与感谢不会转成身份介绍。生成短答按句段过滤已观察到的越界内容，补上波浪号连接的句段，避免连有效接话一起删掉。教练默认篇幅限于教学，明确“一句话”继续优先。是否已介绍仍由 LLM 根据当前会话前文／摘要判断。

[原生三轮记录](native.json) 来自独立测试 App 新会话，逐句通过 CUA 发送、观察最终文本，再只读核对实际运行：

| 输入 | 实际回复 | 整轮耗时 |
| --- | --- | --- |
| 你好 | 你好，我是 Review Today 的学习教练，可以帮你理解知识、梳理资料、检查理解。你可以直接问我问题，或者把想弄懂的材料发给我。 | 3.546 秒 |
| 你好吗 | 我挺好，谢谢关心～ | 3.325 秒 |
| 真的吗 | 真的呀，状态还不错～ | 3.755 秒 |

共 3 次 Jev、3 次入口 LLM；三轮均保留部分 Jev 局部结果，不确定项由 LLM 处理。没有教学／回答节点调用、任务或录入。原有一条用户会话的四条消息指纹与 [重启前](history-before.json) 相同。当前 App 保持打开；侧栏新建会话后说“你好”或“你好吗”即可复验，旧坏回复保留。

## 验证及失败保留

- [全量受控](controlled-tests-final.txt)：694 tests / 320 subtests，通过。最后仅调整短句分隔和已观察到的邀请句筛选，再运行相关 [83 tests / 52 subtests](targeted-tests-final.txt)，通过。现有 4 条 FastAPI 弃用警告保留。首次从仓库根目录直接调用 pytest 导致测试包导入失败，改用项目隔离入口后完成检查；该收集错误不计作产品测试失败。
- [第一批](live-01.jsonl)：20 轮，原断言 16/20。三次开始方式断言只接受“你可以”，误伤“直接提问”等有效说法；一轮混合问题多加了例子。人工复核还发现纯反馈插入介绍，已收紧反馈路径并保留原结果。
- [第二批](live-02.jsonl)：20 轮，原断言 18/20。一项仍把“直接发我”误伤，另一次能力问句多走教学准备／回答节点。人工检查发现波浪号连接的有效接话被整句过滤成无关保底，以及重复材料邀请，随后修订句段处理。
- [最终批](live-03.jsonl)：20 轮，原始自动结果 19/20。唯一失败为基线首句使用“弄懂知识／讲清楚”，断言却要求字面“理解”。修改评测器接受同义能力表述，对同一批原始输出重新核对，20/20；未重跑模型、未覆盖原始失败。差异、原始文件摘要和人工结论见 [复核结果](reviewed-03.json)。

最终覆盖首次问候、首句“你好吗”、介绍后的问候与追问、固定重复前文的反馈、显式身份能力询问、反馈／问候混合知识问题和引用投诉句。原始 JSONL 保留提示、模型请求响应、代码摘要、状态和用量。最终批次的生产代码摘要与交付源码一致；其后仅修正评测同义表述断言与案例登记，未改变生产行为。
