### 实际修复和公开核验

第一次知识生成把“适用边界丢失”的两处非相邻原文拼接成引文，确定性检查拒绝其 `evidence_excerpt` 和 `scoring_spec.evidence`。两个具体字段问题作为待修正数据传回现有一次修复；真实模型返回连续原文后重新通过检查。首稿和修复输出均保留，没有人工替换，也没有额外手动重试。两次语义核验均返回 ok；本次具体问题由程序的连续引文检查发现，不能把它表述为模型核验发现。

实际发生一次 RiskVerdict、一次按需公开查询准备和一次 VerifyVerdict。网页操作为 DeepSeek 搜索一次、Exa 正文读取三次，四次均返回；现有核验给出 confirmed 后才进入本机保存。来源和真实输出见 [repair-and-verification.json](repair-and-verification.json)与 [live-events.jsonl](live-events.jsonl)。此处记录运行结果，没有重新独立审定所有网页事实或把模型 confirmed 当成普遍准确率。

第一次回复中的退款天数是模型明确标为“假设”的教学例子；保存范围只取适用条件的机制，不把假设天数写成实际退款规定。Python 问答保留在历史，但没有进入 RAG 冻结保存来源或卡片正文。
