# 知识卡状态连续性验收补修

Rex 的实际截图证明上一轮尚未完整解决问题：旧回复称“已记录两张 RAG 知识卡”，新回复只换成通用的“还未整理”，既没纠正矛盾，也没点明刚才回答的知识点。只读核对确认新服务已生效，因此不能归因于旧代码未加载。

## 本次改变

- 状态查询在同一次入口判断中选出实际讨论主题和待纠正的旧断言。程序核对消息、逐字引文与主题来源后，组合真实保存状态；不把自由回复里的“已保存”当事实。
- “刚才回答”围绕最近的题目、作答和反馈，不能把较早讲过的切块或错位计划标题混进来。旧题反馈仅帮助识别讨论主题，不因此成为已验证知识或掌握证据。
- 没有保存回执时，在新回复里纠正旧的正向保存断言；不改写旧消息。完成纠正后再次查询不重复纠错。存在真实历史保存回执或已生成内容时保守处理，不把可能真实的旧说法一概撤回。
- 纠错引用必须保留句首／段首限定与完整分句边界，不能从“目前还没有保存知识卡”截出“保存知识卡”来撤回原本正确的话。边界核对不证明整句话是否正向，仍依赖同次语义判断；不新增判断调用。
- 兼容旧版无副作用的产品状态回复，使其不再挡住讲解来源；显式保存可指向本段讲解或反馈，但不能借用另一段的消息。旧未绑定反馈仍排除在卡片事实之外，并提示覆盖限制。
- 有来源却未提供有效主题引用时，沿用一次结构恢复；仍失败则报告失败，不悄悄退回通用话术。失败路径沿用既有运行错误处理，可能标记关联任务为可重试失败，但不改变学习计划、作答证据或掌握记录。

本次没有改变自动生成／入库规则。答完就自动整理待确认、自动入库或继续手动触发，仍待 Rex 选择；状态询问本身不授权整理或保存。现有生成步骤说明保留。
