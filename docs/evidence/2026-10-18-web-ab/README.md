## 搜索、兜底与读取的实际表现

- DeepSeek Search 9 次均有结果，工具操作中位 0.416 秒；Exa Search 12 次中 10 次成功、2 次超时，中位 11.037 秒；Tavily Search 5 次成功，中位 4.332 秒。这些含各适配链路、握手和服务时间，不是独立搜索引擎的统一基准。
- 读取有 Exa 18 次、Tavily 5 次工具成功；正文成功仍须判断是否有用，APA 壳页就是反例。本批 **DeepSeek Fetch 和 Browser 实际调用均为 0**，因此没有新增 Fetch 优于 Exa 的证据；早期单工具验证仍见[原记录](../2026-10-18-deepseek-web/README.md)。
- 有界补查和故障备用均实际发生，且所有问答都停止在既定额度内。DeepSeek 优先的合格回答也依赖 Exa／Tavily，不能把最终合格率归为 DeepSeek 独立检索胜率。
- 按冻结方案保留同进程冷却。Exa 超时共引起六次后续跳过，涉及 HTTP 与 Kubernetes，跨两种配置；HTTP 的 Exa 优先项实际从 Tavily 开始。该状态干扰、模型自行生成的不同 query、上游缓存和格式重试都会影响对照，**不能将 25.2% 全部归因为搜索顺序的因果效应**。原失败和跳过未剔除，见 [tool-observations.json](tool-observations.json)。
