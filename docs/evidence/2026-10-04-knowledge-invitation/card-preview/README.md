## 已落地

- 保存前显示实际知识标题、少量来源明确的要点、一句总结及「未保存」。同知识补充／纠正同步替换本版本预览；旧邀请或无可靠预览保留原范围说明，不造要点、不后台补生成。
- 点击「保存为知识卡」才完整生成／核验／保存；失败保留内容，实际回执后保留简略卡并开放真实详情。复习独立且默认关闭。
- 完成时详情入口一次局部银白轻亮，之后保留静态浅底；打开后恢复普通样式。重复回执与历史不重放；减少动态静态反馈。
- 标题采用系统 `title3` 半粗体，要点与总结采用 `body` 常规，与聊天正文协调；辅助信息为 `caption`。复制工具移到卡片后。修复要点未进入原生 AX 的问题，内容更新时同步更新可访问名称。
