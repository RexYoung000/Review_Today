## 保留的失败证据与限制

[首轮文字](text-first-trial.json)显示模型曾因过度保守而不排版，也曾尝试删除“不要不要”；后者被拦截。[首轮音频](audio-first-trial.json)包含 4 次整理回退，排查发现“语音输入”误触发格式指令保护及长文漏报编号依据。已修正误判，新增严格限定的口述序号等价比较，并要求先输出编辑依据再生成正文。最终仍保留上述 1 次长句无效输出，未自动重试计费识别。

编辑依据与白名单限制只能约束改写，不能证明模型理解了所有语境；不确定时保留原文。现有声学无声检查不是人声或身份识别，环境噪声/未清晰采集时仍可能产生短识别结果。暂不调整模型或扩大本轮到声纹/实时识别。

复跑文字对照：在 `agent-service` 执行 `.venv/bin/python -m tests.dictation_cleanup_eval --live --output /tmp/dictation-comparison.json`，会产生真实文字模型调用。音频报告的 source 字段为非敏感合成内容，可用 macOS Tingting/Meijia 重建；不提交音频、不读取真实用户草稿作为样本。

日常验收入口：`/tmp/review-faithful-build/Build/Products/Debug/Review_Today.app`。在 Agent 输入框点击麦克风，用本人近讲录音检查“第一/第二”“口误”“不是…而是…”“另起一段”，结束后检查草稿并尝试 ⌘Z。最新提交状态见主验收文档。最终体验验收保持开放。
