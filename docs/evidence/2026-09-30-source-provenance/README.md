# 来源身份与网页版本回归收尾

日期：2026-09-30。范围为两项既有回归失败的定位与修复，沿用 [Harness §17.4](../../agent-harness-v2.md#174-来源交接与实时性)。不新增产品规则。

## 核实结果与改动

1. **网页刷新断言对象错误。** 旧测试直接读取 `sources[0]`，材料读取流程现在还保存用户输入记录，因此第一项未必是网页。隔离追踪确认显式刷新已取得新正文、版本 2 与版本 1 历史。本次按准确网页 URL 取回来源，保留并加强原断言：来源唯一、类型为公开网页、ID 不变、版本由 1 到 2、新正文正确、历史与原快照完整相同。首次生成失败后的重试只读取一次，显式刷新才读取第二次。网页刷新实现未变。
2. **混合资料丢失生成来源。** `conversation_materials.prepare` 曾在重新整理材料时直接排除生成讲义，随后覆盖任务来源；既有回答的来源身份因此丢失。现在同话题的已有讲义与新用户资料均保留，回答标记混合来源，旧讲义的 ID、类型、版本、正文和定位保持不变。新话题和失效记忆仍沿用原隔离规则。
3. **材料充分性边界保留。** 生成讲义保留为学习来源，但不进入外部材料充分性检查的来源列表。指定页面无法取得正文时，旧讲义不能让系统误判为材料已提供；缺材料回应也不删除讲义。

没有改写日常历史、补发用户消息、自动入库或改动复习排期；此前已丢失的来源不会被本次修复凭空重建。

## App 验收入口

在 Agent 新会话中选择资料学习，明确要求“直接教我 RAG”，再补充一段实际资料并要求继续解释。预期沿用同一学习任务、同时保留前面讲义和新资料的来源归属；已有理解／复习成绩不因补材料自动提升。若回答失败，点击该轮重试，成功后应无重复材料或重复回答。

另一场景是提供无法取得正文的链接：系统应请求必要正文，不能把前面讲义称为该网页内容。网页刷新版本、旧快照和来源 ID 由隔离自动化验证，界面没有要求 Rex 检查内部字段。

本轮工程验证不等于真实模型措辞质量、最终原生体验或 M1 全体验收通过。
