# 背景补充与学习目标分流修复（2026-09-22）

状态：实现、受控回归、真实模型回放与原生 App 自测完成；当前 Jev 测试实例已加载新版本，体验待 Rex 验收。日常供应商、Jev 开关、正式复习和排期未修改。

## 原因与修复

现场为“嘿”→“你知道我是谁吗”→“我在准备ai产品经理的面试”→点击“继续放在这里”。并不是外部会话目标串入：程序把本会话中的普通身份问题写成学习目标，背景补充又被 Jev 标为 goal，而 LLM 同时判断 scope=conversation。合成结果缺少冲突检查，错误弹出位置确认；位置按钮复用该结果后，仅凭 goal 标签建立学习任务，再固定询问已经给出的学习用途。

- 新增 background 对话类别，承接用户提供的背景，保留后续知识问题、明确教学和已有任务中的作答／澄清。
- 普通问题不写入学习目标；旧 focus_goal 字段不能单独证明已有课程。当前有效任务才参与目标保护。
- Jev goal 与 LLM 的对话范围冲突时交完整 LLM；即使完整结果仍含矛盾的 goal，程序也不允许仅对话结果建任务。规则更新为 `jev-entry-3`，未完成的旧意图重新判断。
- 位置按钮仅处理会话位置。明确学习后的目标澄清使用已知用途询问具体缺项，替换固定反问。身份说明也不再把没有个人档案概括为完全没有跨会话学习记忆。
- 仅对有证据的、无学习进度的旧误建任务在下一轮撤销状态；原消息和真实学习任务保留。

## 人工复核与复验

本例前三轮、背景补充、首次学习与真实目标切换已按预期处理。语言质量仍有限：最终 Jev 的一句话 RAG 问答追加了第二句；学习讲解有把向量检索描述为 RAG 必需方式的过度概括；“先确定准备哪块”的学习安排输出比基线更长，末尾仍问了两个方面。它们没有导致本次背景误建任务复现，但不能以路由通过声称回答内容和澄清粒度全部合格。此次没有为这些额外语言问题重跑刷结果或扩展为教学内容重构。

验收入口是当前打开的「Review Today · Jev 测试」中最新的“嘿”会话。可继续回答想了解的具体方向，或新建会话重复前三条输入；应直接承接背景，不显示“原目标不同”的位置确认。原来的“嘿”会话保留在下方，历史错误文字仍可见，不代表新轮次沿用旧规则。

复验命令：仓库根目录执行 `bash agent-service/run-controlled.sh`；真实模型在 `agent-service` 执行 `.venv/bin/python tests/background_routing_real_smoke.py --live --output <新的结果路径>`。沿用已有安全凭证来源与临时库；网页与知识写入被阻断，因此不作为这些工具的成功验证。普通问题与真实学习请求的概率阈值仍待独立样例校准。
