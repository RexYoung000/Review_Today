Rex 已确认决定 243，仅修“独立普通插问清空原任务来源”，先零新增真实请求受控复验。原 EVAL-03 30／30、余 0、STOP、失败与日常数据保持；不使用已耗尽预算、修改供应商或执行真实保存。

先同步 [Harness](../../agent-harness-v2.md#knowledge-save-invitation-contract)，复用现有独立问答隔离，覆盖手动学习模式中的独立普通问题。隔离须先于材料读取和来源准备／回答写回；同主题追问继续使用原任务，真正新目标及有状态动作保持原路由。来源只服务本轮问题，原计划／题目和冻结邀请／保存输入保持。

生产仅修改 `dialogue_routing` 的既有局部问题资格复用，以及 `ConversationHarness._respond` 的入口隔离。明确 new_topic／conversation／answer_only，且只有普通问题／追问／举例／提示、无绑定操作、拟执行动作、模式切换、直接教学、续学请求、综合检查或 JD 请求时，在本轮非教学回答中使用既有 dialogue_only。材料准备、教学准备和回答收尾统一不再取得旧任务的写入对象；原会话 active_task_id 与学习模式保持。Auto 原规则等价复用，不扩大新目标、同主题或保存的授权。
