## 建议的单条流程

同一个全新隔离会话、空知识库、独立服务和原生存储，从默认启动开始连续执行。讲解、题目、评分、预览、整理及核验均由本次现有模型产生，不导入旧讲解、旧邀请、旧保存结果或冻结输出，不复用旧探测结果。关键路径需中断、重启或恢复时留证，不能报告为不中断连续通过。

| 步骤 | 用户动作 | 通过条件 |
|---|---|---|
| 1 | 新学习一个 RAG 知识点：高相似度为什么不能保证答案正确 | 本次真实讲解与题目涵盖来源错误／过时、生成不忠实／省略条件及核对依据；尚无知识卡 |
| 2 | 只回答相似度及来源风险，故意漏答生成风险和核对条件 | 肯定正确部分并要求补答，不认证全题或触发通过后的邀请 |
| 3 | 针对实际补充题，完整回答题目必要内容 | 仅记录本题实际概念；出现标题、少量要点、一句总结的未保存预览；整节仍未验证 |
| 4 | 同一知识点补充／纠正自己的措辞，再短暂询问另一主题 | 依据本次真实话语检查原邀请内容与版本更新，旧无效表述不入库，另题不并入；不预设模型一定说过某个错误 |
| 5 | 明确回到原 RAG 预览，在原生点击当前显示版本的保存按钮 | 按点击范围实际整理和核验；未有匹配本机回执时不称已保存。确需联网时沿现有安全公开查询及证据流程，不为通过强制降低风险 |
| 6 | 等待保存完成 | 本机真实落盘的卡片、来源和归属与服务匹配 ACK 一致；无重复保存，复习默认关闭 |
| 7 | 打开实际卡片详情，明确询问原 RAG 范围的保存状态 | 详情来自真实卡片；自然查询所报数量／名称与实际回执一致，不借另题或旧卡冒充 |
| 8 | 核对原学习目标与步骤，退出后用新进程读取磁盘 | 学习记录保持；保存不自动升级整节掌握或推进下一节；原生输入、回复、Run、卡片与后台一致 |

第 3、4 步的回答依据当轮真实题面和已说过的内容准备，不能预填理想模型输出；每步做状态核对和人工语义阅读，任一关卡未达到预期就停止。新发现问题只留证和限定下一项，不在试跑中悄悄扩大整改。
