## 整轮行为单独报告

现有 DeepSeek 流程在 31/31 固定场景、317 项自动检查中全部通过；真实语义调用 62 次（IntentDecision 31、TeachingPreparation 15、ConversationOutput 15、ContinuationChoice 1），账本记录 62 次 HTTP 请求和 62 条返回用量。

重点复核：混合请求回答知识；A001 暂缓后未续讲；A013 转场只问下个主题且未接走其他目标；A015 承接代办保留范围限制；旧历史和任务保护检查通过。整轮耗时中位数 3,148 ms，范围 1,480–9,314 ms；有 `first_text_ms` 的 15 例中位数 3,674 ms，范围 2,953–4,967 ms。无首字记录的固定短回复没有补成零。

该层报告 token 为输入 266,937、输出 15,845、缓存输入 246,144；按同一价格表估算 USD 0.013364–0.026729。执行器说明的模型可调用性探测不纳入语义调用账本，可能产生额外少量请求，因此不把这 62 次称为整个进程的全部网络调用。

执行使用每场景独立临时数据库，网页和知识写入被拦截，实际阻断调用企图为 0；不是网页可用性或保存成功验证。Jev 没有完整路由实现，没有与此配对的整轮表现/耗时；没有验证原生 UI、连续生成式多轮或 Rex 最终体验。不能将“局部 Jev 更快”和“当前 DeepSeek 整轮通过”合并成“App 已提速且通过”。
