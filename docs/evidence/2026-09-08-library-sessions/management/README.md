# 会话组织与知识管理验证（2026-09-08）

已实现并完成下列工程及原生自测，最终视觉和手感待 Rex 验收。本记录覆盖本目录的新方案；此前同日二级工具栏、独立数字列表属于历史版本。

## 已接入

- 会话侧栏仅保留搜索和新建，空列表隐藏搜索。搜索为居中卡片，按未归档会话的标题/标签检索，结果注明文件夹；支持输入焦点、上下选择、Enter、Escape 和关闭回焦。
- 新建显示唯一草稿和短过渡，反复点击复用；非空草稿保留。首次消息本地保存成功才成为正式会话，稳定 ID 不变，失败保留原文。
- 单层文件夹支持创建、移动、重命名、折叠和删除；删除文件夹保留会话，归档/恢复保留归属。旧数据库升级后会话默认未分类。
- 设置中的已归档聊天独立搜索、查看、恢复、多选和删除；搜索变化清空勾选，批量动作只处理可见选中项。查看复用主窗口并保持只读，主窗口关闭后仍可重新打开。
- 知识按主题和当前状态多选、全选、暂停、恢复及移到回收站；单卡菜单同样可用。回收站不自动清空，恢复保留进度；永久删除需确认知识、题目和相关复习记录，保留历史文本及共享来源。回收站不提供试题入口，撤销恢复原状态。
- 连续竖向定位条显示总数和当前序号，点击立即更新、上下拖动实时换卡；横向/键盘循环翻阅、单栏正文与后层卡继续沿用。

## 延迟排查

没有固定 0.5 秒等待。采样定位到列表排序反复解析所有相邻标题，卡片数量增加后会阻塞主线程。现按列表/分组一次计算显示标题及重名区分，并避免闲置后层卡构建正文；标题生成规则与数据保持。

| 隔离 DEBUG 测量 | 修复前中位数 | 修复后中位数 | 修复后最大值 |
| --- | ---: | ---: | ---: |
| 25 张 | 188.9 ms（27 次） | 73.0 ms（14 次） | 77.7 ms |
| 100 张含长正文 | 5381.2 ms（仅 2 次） | 99.8 ms（15 次） | 112.9 ms |

测量从定位输入处理开始，到所选卡片的 AppKit 绘制回调；不是屏幕实际亮起延迟，也不证明所有设备稳定达到 100 ms。连续拖动可能合并中间样本，100 张修复前样本不足以作为稳定基准。原始毫秒样本、统计方法与限制见 [性能记录](locator-performance.json)。
