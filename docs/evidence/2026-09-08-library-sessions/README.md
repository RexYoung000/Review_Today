## 单栏区块修订（2026-09-08，B 方案已接入）

Rex 确认以少量区块与留白替代内部线条。知识卡现为单栏：浅灰主问题、白底详解、浅灰判断关键点、同区折叠的常见误区、可展开来源。标题和底部操作固定，正文统一滚动；取消黑色编号底、判断对错图标及内部分隔线。尺寸上限为 760×680 pt，窄窗正常换行；仅重排原文，不修改知识数据。

底部不明显主要来自预览中的小露出量、同色卡面及缺少层间阴影；旧原生宽卡也存在低对比。现按卡高补偿缩放，每层保持 24 pt 的实际露出，加入短阴影与主题适配明暗差；底部操作留出 32 pt，后层不露按钮残影。保留居中向下叠放与原有翻阅方式。

原生检查同时发现旧解释排版器会把普通段落自动编号，并限制到前 6–8 段。现仅识别明确行首列表，完整保留普通段落、重复段落、标点、省略号、小数和版本号。增加正文不丢失的回归；详解、判断要点和误区均不再限制条目数量。

已在原生标准浅色窗口、最小深色窗口并展开 280 pt 侧栏，分别把标题拖到左侧栏内部、再反向返回；确认卡片和阴影没有跨过内容区边界。短拖回弹与连续左右键正常。正常速度录像：[浅色边界与淡隐](soft-blocks/pane-transition/wide-light.mp4) 19.55 秒、[窄窗深色](soft-blocks/pane-transition/minimum-dark.mp4) 8.68 秒；[过渡帧](soft-blocks/pane-transition/fade-at-pane-edge.png) 同时可见边界裁切和透明度变化。只录制隔离验收进程自己的窗口，无音频、无加速。
