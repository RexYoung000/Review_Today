# 独立新会话验证（2026-09-08）

本轮把唯一草稿入口替换为普通会话。每次 ＋ 保存独立本地会话，输入按会话保留，第一次发送复用其 ID；旧非空起始草稿保存为普通会话。新会话共用搜索、文件夹、标签、归档及删除菜单。删除当前会话后输入不回流到起始页。空会话没有消息或运行时不提交模型请求。

## 已验证

- `IndependentSessionContractTests`：临时真实磁盘；旧草稿保留与失败回滚；连续创建、输入分别保存及重开；创建失败不留下额外会话；首次发送失败保留输入，重试不重复会话；空/有内容的 active 会话删除、删除标记和草稿不复活。active 删除标记预留先归档再删除的两个版本，服务接口不变。
- `SessionDeletionContractTests`：取消无副作用、保存回滚、范围变化再次确认、共享知识保护、批量清理、持久删除标记。
- `SessionOrganizationContractTests`、`LearningInputContractTests`、`LearningMemoryContractTests`：起始页首次发送回退、文件夹与归档、输入保护及记忆排除草稿。

## 原生操作

隔离预览中连续 ＋ 创建 A/B，分别输入不同内容；来回切换完整保留。删除当前 B 后起始输入为空，A 不变。新会话右键菜单包含归档、删除会话、移动到、编辑标签、记忆设置；成功新建文件夹并移动空会话。搜索「新会话」找到两个普通条目，分别显示文件夹；Escape 回焦。标准 1280×820 与最小 760×652 窗口、浅深主题及预览减少动态开关均操作检查，收起栏 ＋ 同样新增并展开侧栏、聚焦输入。

## Rex 验收路径与边界

侧栏 ＋ 连点两次 → 各输入不同内容 → 来回切换 → 悬停条目点击三个点 → 移动或删除一个 → 确认另一个内容仍在。可退出重开检查空会话及输入保留。

磁盘重开与发送事务由真实 SwiftData 契约覆盖；UI 删除在隔离内存预览执行。未重验真实模型回复、日常服务端删除清理闭环、完整 VoiceOver、实际多语言或系统级减少动态开关。最终体验由 Rex 验收，未发布或关闭 M1。
