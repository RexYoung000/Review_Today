# Jev 入口逐项合成验证

已实现并完成隔离验证，日常 App 仍关闭。入口现在保留无冲突的 Jev 局部判断，只补判不确定或冲突的项；本批 14/31 轮实际采用了至少一项 Jev 判断。工程合成生效，不代表入口准确率达到日常接管要求，也没有提速或降本证据。

## 实现与责任

规则版本 `jev-entry-2`，模型固定 `jev-1.13.0`。DeepSeek 继续使用现有 router=`deepseek-flash`、coach=`deepseek-v4-flash`、risk=`deepseek-v4-pro`，未改供应商配置。

- 无当前任务、目标、摘要、前文或待处理对象的空白会话，程序确定为新话题，不询问 Jev。修正旧规则中“首次请求也可标为延续”的定义。
- 手动模式由程序控制；Auto 普通问答及社交不会被模式建议变成学习任务。
- 合法 `unsure` 只使对应字段待补判。LLM 返回有类型限制、带原因的局部更新；未补齐不能默认视为“不需要”。结构或概率非法仍整批回退。
- 控制、产品边界、跨会话续学、纠错、作答等保留完整 LLM 判断。混合请求和无法安全合成的结果完整交回。LLM 完整替换与 Jev 标签相同也不算 Jev 采用。
- 逐项保存原始选择、最终值、来源和原因；原始概率不改写。程序确定项不算 Jev 成功，旧快照仍可读取。默认五秒、无自动重试、认证停用、预算、取消及迟到结果约束保留。

入口仍调用一次 LLM；这次没有引入“普通请求完全绕过 LLM”的执行路径。候选筛选、评分标准和正式复习排期未改。

Jev 单节点耗时中位数 1.861 秒，范围 1.322–5.028 秒（包含超时退出开销）；没有命中旧缓存。两个分支共 155 次 HTTP 请求，已知费用 0.029641–0.057080 USD。估算沿用文件头保存的 2026-09-20 官方价格快照（[TypeSafe](https://docs.typesafe.ai/models)、[DeepSeek](https://api-docs.deepseek.com/quick_start/pricing/)），区间包含闲时/高峰等条件，不是扣款账单；缺失用量不能视为零或总费用上界。

本批没有减少 DeepSeek 调用，增加了串行 Jev 调用，整轮更慢。旧实验的 4.764 秒与本批 6.321 秒也不是受控性能对照，不能用服务可用性的变化证明实现快慢。字段合成改善与整轮性能应分别评估。

## 失败与语义复核

- `A006-repair-question`：Jev 仍把会话纠错判成 `social`，LLM 返回完整纠错判断并回答原问题。这是真实局部错例，没有被提高采用率的规则绕过。
- `A015-links-after-promise`、`A015-mode-and-errand`：Jev 超时，沿原节点处理，未进行下载或网页外发。其中一次后来返回用量，只计账目、不采用迟到结果；另一次用量未知。
- 基线 `A013-current-plan-next`：入口已正确识别沿当前计划继续，但讲解节点 `RT.MODEL.SCHEMA` 失败，没有产出回复。这不是入口分类错误，也不能把实验分支成功归功于 Jev——该轮实验入口同样完整交给 LLM。
- 实验分支 `A017-internal-material` 回复仍称“可以在本地做一点梳理”，不准确：材料经过外部模型，实际保证是没有交给网页服务。该话术问题此前已存在，本批没有修复，不能称隐私表述通过。
- 实验分支 `A013-current-plan-next` 的生成讲解出现“检索保证不遗漏，重排保证排序质量”的绝对化表述；这是后续 LLM 内容质量问题。整轮结构自动检查未覆盖所有知识事实，不等于内容全部正确。

工程交付完成；入口保留为隔离实验、继续校准。此次不增加日常自动放行阈值、不启用日常 App，也不把 31/31 自动检查替代 Rex 的产品验收。
