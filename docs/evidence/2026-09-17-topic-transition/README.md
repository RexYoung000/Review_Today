# A013 当前话题转场与旧目标续学

## 定位与修复

Rex 在大模型生成原理的讲解后说“好的，先这样吧，我们学下一个内容”。日常记录的意图是 ordinary / continue / conversation / content，澄清内容已是询问下一主题。随后 `continuation_intent` 却把“我们学下一个内容”认作恢复旧目标意愿，触发候选查询并覆盖本轮澄清。该会话没有 LearningTask，但有正常对话上下文。

跨会话处理现在先检查范围：普通 conversation 或缺下一主题的 content 澄清，不凭 continue 标签查旧任务，也不进入续学补判。真正的 continue_goal / resume_target 漏字段仍可补判，使用当前上下文、严格区分本地转场与跨会话恢复；补判否定时回到当前内容的局部回答，不创建课程。显式操作优先沿原授权流程。提示规则同步区分无计划问下一主题、有计划讲下一步、明确旧目标恢复；不推断“好的”代表理解或保存。

## 真实模型回放

[live-replay.jsonl](live-replay.jsonl) 使用现有 DeepSeek 配置、合成输入与独立临时库，9轮全部通过：

1. 普通原理问答→截图原句→具体 RAG 问题。转场回复“接下来想了解什么内容？”，随后正常解释 RAG。
2. 其他会话存在未完成 RAG 课程时，再做原理问答→截图原句；仍只问下个主题，旧任务完整保留。
3. 当前确有 RAG 计划时发送同一句，讲下一步“检索与重排”，不更换目标或标记掌握。
4. “算了，晚点再学吧”简短收尾，不续讲。
5. 新会话明确“继续上次没学完的 RAG”，正常交接同一目标；明确恢复无匹配的光合作用时，诚实说明而不建课程。
