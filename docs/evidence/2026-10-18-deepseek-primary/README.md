## 实际改变

- V2 日常问答及各学习模式的来源准备复用已有正文判断；首批来源不足、部分支持或没有可用来源时，最多发起一轮质量补查，从实际返回服务之后接续备用链；服务故障仍按原规则有界切换。充分支持即停，分歧不触发换服务。普通两份成功正文／两次判断，交叉三份／两次的总额不重置，沿用十次网页调用、整轮时间、取消、冷却与精确 URL 守卫。
- 本轮现用 LLM 来源选择和核验同时收到本轮完整问题、明确来源要求；补查选择还收到上次缺口与已尝试地址。网页服务依然只收到原安全公开 query，完整问题只交现有角色模型，不新增独立打分调用。
- 两次空搜索上限跨补查共享，并保留在可复用结果中；已到空结果上限时，取消仍优先。补查失败或仍不足保留具体限制。指定 URL 与知识保存的确认／风险／不足即不保存规则保持。
- DeepSeek 读取没有观测到最终跳转地址时，正式来源准备保留请求地址及原始元数据，不因缺少 `final_url` 键而丢弃成功正文。
