# 知识卡轻纸面 · 原生对照

最新版本已按 Rex 反馈改为分区阅读，误区与来源常驻。见 [分区修订及最新截图](reading-blocks-r2/README.md)。下文保留首轮记录。

本轮交付独立原生小样；日常 App 默认旧样式。使用内存合成知识，不连接模型、不写正式复习成绩。主题、知识原文、评价标准与业务职责保持原样，新的内容样例仅用于排版。

## 打开与比较

运行 `bash tests/mac/run-library-session-preview.sh`，打开 `output/library-session-preview/ReviewTodayLibrarySessionPreview.app`。窗口底部可切换「当前版／轻纸面」、浅深色、减少动态、截图与录制。开始时展示一张合成知识卡；关闭后可选「向量嵌入和向量数据库在 RAG 检索中的作用」比较长内容。

菜单「验收」中 ⌘⌥1 为默认尺寸、⌘⌥2 为最小尺寸；⌘⌥B 切换版本、⌘⌥D 切换主题。原型工具条另占空间，不属于产品页面。试一题和卡内管理操作显示模拟说明；参与开关只改变原型局部状态。

## 实现

轻纸面统一标题、详解、判断要点和来源的阅读对齐，只对主问题轻量强调。主题顶栏与紧凑操作区固定，标题完整随正文滚动；后层露边 8pt，保留原有横向翻阅、短拖回弹、定位条与键盘。

连续开合只改变外壳边界，正文按最终字号淡入。返回位置从当前可见列表卡片取得；来源不存在或滚出可见区时淡出，不强制滚动。旧动画完成回调无法覆盖取消／关闭状态。首次原速录像发现来源位置传递失败，已转为在覆盖层直接解析 SwiftUI 几何锚点，并补上首帧来源位置；最终录像另行归档，不用首次失败录像充当验收证据。

原型构建脚本修正了 macOS 27 主机编译依赖时的最低版本不一致，并把 FSRS 动态库随小样打包，避免依赖 /tmp 构建路径；项目支持版本与算法不变。

## 验证与证据

运行环境为 macOS 27.0（26A428）、Swift 6.4；产品最低系统要求不变。原型独立构建、日常 App Debug 构建，以及 `KnowledgeDeckNavigationTests` / `KnowledgePaperTransitionTests` 均通过。后者覆盖旧回调失效、开合打断、重复完成、尺寸变化、来源缺失／越界和薄卡堆几何。

原生实际操作确认：同内容切换旧版／轻纸面；浅深色；默认 1280×820 与最小窗口（760 宽，产品内容 620 高，额外原型工具条和窗口装饰另占空间）；长标题完整换行；正文滚动、误区与来源展开；缺少主问题时显示原因且禁用试题；试一题仅出现原型说明；方向键连续反向；定位条递增；短拖后仍为当前卡；Escape 关闭；可见来源关闭后 Return 重新打开；减少动态时直接开合；无可见来源关闭后列表滚动位置保持。

初轮还发现焦点虽然回到卡片，但 Return 未激活的问题，已补齐轻纸面模式的 Return／Space 激活并用 Return 原生复测。没有将完整无障碍验收记为通过：全窗口 Tab 顺序仍可到侧栏，VoiceOver、Switch Control 未实际运行；触控板惯性与真人长时间手感待复核。开合途中精确毫秒取消由状态契约覆盖，未把该项写成原生手工通过。日常接入与 Rex 视觉接受仍开放。
