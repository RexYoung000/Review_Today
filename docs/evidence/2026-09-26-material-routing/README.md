## 真实模型与实际调用

使用独立临时数据库、合成岗位/产品内容和当前模型配置。JD 及产品网页由合成读源控制；最后一个 Python 文档链接使用真实网页服务读取。格式恢复用“真实模型输出后注入一次格式错误”验证，不伪称供应商在该案例自然出错。

| 场景 | 整轮耗时 | 模型请求数 | 实际输入 / 输出 token |
|---|---:|---:|---:|
| 问候 | 2.304 s | 1 | 9,727 / 346 |
| 面试背景 | 2.255 s | 1 | 9,898 / 360 |
| JD 空壳页面，等待正文 | 5.418 s | 3 | 13,713 / 785 |

| 实读 Python 公开文档，简短回答 | 9.455 s | 4 | 17,817 / 817 |
