## 已实现

生产只改两处现有入口：预览展示与更新请求复用同一个连续引文定位规则；明确返回的结构化更新预览，在请求校验时先核对选中的旧片段和新引文，越界即报固定字段位置／错误类型，进入已有一次输出修复。错误不包含引文原文、用户资料或外部指令。发布事务仍再次核对，修复不通过则沿原回复未完成流程，不发布更新结果或授予保存。

更新指令只补充本类错误的修复说明，原 system 缓存身份随指令变化；旧规则输出不当作本轮新校验已经通过。没有新模型角色、独立核验、保存或 UI 调用。未返回／结构异常的可选预览、首次评分邀请及旧数据兼容保持；本修复只处理引用越界，不把引文定位当作语义正确性保证。
