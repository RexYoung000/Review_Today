## 固定的路径与通过标准

| 顺序 | 验什么 | 通过时用户应看到什么 |
|---|---|---|
| 1 | 全新讲解与出题 | 解释高相似度为何不保证答案正确，题面包含来源、生成和核对要求；尚无知识卡 |
| 2 | 故意漏答 | 肯定正确部分、要求补齐缺口，不能直接判全题通过或邀请保存 |
| 3 | 完整作答 | 只认该题覆盖的知识点；出现标题、少量要点、一句总结的未保存预览 |
| 4 | 同点补充／实际纠正 | 更新原预览，反映本次有效补充；暂不保存，不杜撰模型说过的错误 |
| 5 | 独立插问再回到 RAG | 另题正常回答，原来源／安排／邀请保持，回切后的回答仍有原资料依据 |
| 6 | 点击当前原生预览保存 | 按点击范围整理并核验，实际落盘回执到达后才显示成功，复习保持关闭 |
| 7 | 全部详情与保存查询 | 实际卡片内容正确；这次保存的数量与名称匹配真实回执，不预设一定五张 |
| 8 | 进度及退出读盘 | 不因保存认证整节或推进下一节，原生与服务记录、卡片和回执一致 |

完整原始请求、必要概念、逐关判定及停止条件先冻结在 [plan.json](plan.json)。第二、三、四步必须阅读当次实际题面与预览再作答，不注入理想模型输出。逐关状态和语义都检查；格式成功不等于内容通过。初次阶段失败、保护冲突、达到任一上限，或必须人工修数据／重启恢复才能继续时均停止留证，不以分项修复后的续验冒充本批无中断通过。
