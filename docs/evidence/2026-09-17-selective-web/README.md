# A011 按需核验、运行反馈和参考链接

## 复现与原因

用户反馈基础概念等待过久、吉祥物过小、阶段文字与详情重复、来源看不出可点击。只读检查实际 `harness是什么意思` 运行：路由 needs_verification=false，首字 42.986 秒，总计 45.014 秒；搜索 7.025 秒、三次顺序正文读取合计约 22.6 秒。旧条件因 new_knowledge 或没有 evidence 强制搜索。模型步骤与供应商遥测又覆盖了当前执行摘要。原文有完整 Markdown 链接，黑色全局强调色让它们看起来像普通正文。

## 实现

- 稳定原理、新概念与普通教学不自动搜索。由本轮真实意图决定查证：明确搜索/来源要求、时效、不确定或高风险实际建议等；不单凭“新知识”“暂无证据”或百分比、年份等词面判断。知识录入原有独立风险检查保留。
- 需要核验时按候选顺序读取并判断，第一篇充分支持即可停止；不足继续、最多三篇。明确交叉核验会检查不同来源站点的支持关系；只有一站时不能宣布完成交叉核验。站点区分基于 URL 主机名（去掉 www），最终独立性/相关性仍依赖证据评估，不能视为来源所有权审计。
- 普通核验累计工具时间 30 秒、交叉/高风险 60 秒；保留原有限流、备用链、取消、来源边界。预算不含模型推理，也不是响应耗时 SLA。
- 直接解释仍保留已讲概念和适用来源上下文；无来源不能凭记忆造可点击引用。未搜索不显示核验失败提示。指定 URL 的正文读取有真实阶段事件。
- 模型尝试/尝试失败、完成耗时和供应商完成日志保留在详情中，不覆盖真实主阶段；最终失败仍按既有流程显示。运行角色画布从 32×28 放大到 64×56 pt，阶段与动态省略号、累计秒数移到下方“运行详情”右侧的圆括号内，累计计时不重置；减少动态效果关闭文字/省略号动画。
- 来源保留原生富文本 URL、蓝色下划线，独立来源标题附悬停颜色、手型和键盘 Return 激活。保留正文选择机制、原始 Markdown 复制及复制链接菜单。最后补充无障碍来源标题，避免朗读仅剩长 URL。
