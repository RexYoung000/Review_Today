# Review Today 产品需求与 POC 边界

> 文档状态：首轮需求边界已确认，待实施
> 更新时间：2026-08-11
> POC 周期：连续 21 天

## 1. 产品定义

Review Today 是一个会主动找用户复习、通过语音回答判断是否真正掌握的个人记忆教练。

它不以收藏、笔记或知识图谱为核心，而是把用户当天接触的零碎知识持续转化为主动回忆训练。

核心闭环：

```text
随手输入
→ Agent 自动理解、核验并拆成知识点
→ 自动加入复习计划并给出简短回执
→ 每日主动发起五分钟语音复习
→ 判断掌握程度并允许用户纠正
→ 动态安排下一次复习
```

POC 首要验证用户是否愿意持续完成这条闭环，不在首轮严格证明长期记忆提升幅度。

## 2. 用户与平台

- 第一轮只服务 Rex 本人，使用真实日常学习内容验证。
- POC 是原生 SwiftUI macOS 应用。
- Mac 提供应用内完整采集，以及菜单栏或全局快捷入口。
- iOS、双端同步和商业化都在 POC 通过后另行评估。

## 3. 知识采集

### 3.1 支持的输入

- 文字：用户直接记录想学习或记住的内容。
- 公开网页链接：Agent 读取页面正文并保留来源。
- 语音随记：先转成文字，再进入统一的整理流程。

每次提交都代表“我想学习并记住这段内容”，Agent 不再额外询问是否加入复习。

### 3.2 快速入口

- 应用内提供完整采集入口。
- 菜单栏或全局快捷键提供低摩擦快速采集。
- 不做持续后台监听。

### 3.3 离线与失败

- 断网时允许继续采集，内容先保存在本地并显示“待处理”。
- 恢复网络后自动继续整理；失败任务不能丢失原始输入或生成半完成知识点。
- 登录、付费、动态渲染或解析失败的网页保留原链接，并提示用户粘贴正文或选中段落。

## 4. Agent 自动整理

- Agent 自动完成转写、网页读取、知识拆分、问题生成和入库，不要求用户逐条确认。
- 一个输入可以拆成多个独立知识点；具体数量由内容决定，不机械追求更多卡片。
- 整理完成后展示简短回执，包括“我理解为……”、所属主题和生成的知识点数量。
- 回执不是确认步骤；用户可以直接离开，也可以展开查看和纠错。
- 原始内容决定用户想学什么。Agent 可以改写为独立知识点，但不能把模型常识伪装成原文事实。

### 4.1 风险触发的联网核验

以下情况自动联网核验并保留来源：

- 时效性内容；
- 精确数字；
- 医学、法律或金融内容；
- 原始来源之间存在冲突；
- Agent 对事实可靠性不确定。

普通稳定概念不强制搜索。联网结果只能核验或补充原始内容，不能悄悄改变用户的学习意图。

核验发现错误或争议时：

- 保留原始内容与核验依据；
- 将知识点标记为“待处理”；
- 用户处理前不进入复习计划。

## 5. 每日主动复习

### 5.1 发起方式

- 每天默认安排一次五分钟复习。
- 首周按用户设置的固定时间通知，提供“立即开始”“稍后提醒”“今日跳过”。
- 系统不连续催促，也不把跳过制造成积压惩罚。
- 系统记录实际开始、稍后和跳过行为；数据足够后只建议更合适的提醒时间，由用户接受后修改。
- POC 不读取系统日历，也不假装能持续判断用户此刻是否空闲。

### 5.2 语音交互

- 复习采用结构化实时语音，而不是自由聊天。
- Agent 一次问一个问题，用户直接说出答案。
- Agent 根据知识点、参考答案和可追溯来源判断回答，不要求用户复述固定句式。
- Agent 自动给出掌握等级，并说明遗漏、误解或已经覆盖的核心含义。
- 用户认为误判时可以纠正；纠正结果立即参与重新排期。

回答不完整时：

- 时间充足时最多给一次不泄露完整答案的提示，并允许用户重答；
- 第二次仍未掌握，或会话剩余不足一分钟时，公布简短参考答案并结束本题；
- 单题不能无限追问或吞掉整段五分钟会话。

五分钟到时自然收尾，未完成项目重新排期，不显示为逾期作业。

### 5.3 语言规则

- 普通知识默认使用用户主语言提问。
- 语言学习内容根据学习意图切换到目标语言，用户可以纠正误判。
- POC 只判断知识含义和关键表达，不评分发音、流利度或语法水平。

### 5.4 动态排期

- Agent 负责把回答映射为掌握等级，不直接随意决定下次日期。
- FSRS 类确定性算法根据每次实际表现计算下一次复习时间。
- 答得差的知识更快再次出现；连续轻松答对的知识逐步拉长间隔；遗忘后重新缩短。
- 新知识进入下一次符合条件的五分钟复习，不安排一分钟或十分钟后的同日重复打卡。

## 6. 轻量知识库

知识库只服务于查看、纠错和建立信任，不扩展成完整笔记工具。

用户可以：

- 按主题和掌握状态浏览知识点；
- 查看原始来源、当前掌握状态、下次复习时间和历史判断；
- 修改知识点、问题、参考答案或语言判断；
- 暂停或删除知识点；
- 处理核验冲突和 Agent 误判。

POC 不提供文件夹体系、复杂标签管理、知识图谱浏览或围绕知识库的自由聊天。

## 7. Agent、数据与服务边界

- 用户不输入或管理 OpenAI API Key；模型凭证和 Agent 能力由产品服务器统一提供。
- 完整知识、来源、掌握度、下次复习时间和复习历史保存在 Mac 本地。
- 服务器运行 LangGraph，只接收本轮任务或会话所需内容。
- 服务器只保留恢复任务、排查错误和统计 POC 指标所必需的短期工作流状态、错误与指标，不把完整知识库作为云端主库。
- POC 明确不录入敏感内容；自动处理的材料视为允许按需发送给转写、模型和搜索服务。

Agent 采用两条独立工作流：

1. 采集整理图：转写或读取网页 → 识别意图、主题、语言和风险 → 按需核验 → 冲突分流 → 拆分知识点 → 生成问题与参考答案 → 返回回执。
2. 五分钟复习图：接收本地选出的到期知识 → 实时提问 → 判断回答 → 反馈或有限追问 → 返回评分与排期结果 → 下一题或收尾。

具体节点状态、接口和异常恢复规则仍待实施前设计，不在本文中提前假定。

## 8. 当前技术方向

- 客户端：原生 SwiftUI macOS 应用。
- Agent 编排：产品服务器上的 LangGraph。
- AI：OpenAI 单一技术栈；Realtime 负责实时语音，Responses 负责结构化整理、掌握判断和风险触发的联网核验。
- 排期：FSRS 类确定性算法；排期状态返回 Mac 本地保存。
- 现有项目复用：Review Today 独立于 CobWeb，只复用其[网页读取](https://github.com/RexYoung000/CobWeb/blob/main/src/lib/web-page.ts)与[知识拆分和来源追溯](https://github.com/RexYoung000/CobWeb/blob/main/src/app/api/chat/extract/route.ts)思路或底层代码。
- 产品验证方法：[pi-app-business-workflow](https://github.com/RexYoung000/pi-app-business-workflow)只用于验证假设、指标和继续／调整／停止条件，不作为运行时能力。

## 9. POC 明确不做

- PDF、图片、外部音频文件或视频文件导入；
- 登录墙、付费墙和需要浏览器会话的网页自动抓取；
- 持续后台监听、本地大模型或离线语音复习；
- 自由知识库问答、通用语音助手或库外问题回答；
- 发音、流利度、语法和完整口语能力评分；
- 完整知识管理、知识图谱、社区课程或复杂笔记编辑器；
- iOS 客户端、双端同步、云端知识主库、订阅或付费墙。
