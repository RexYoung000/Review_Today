# Review Today 产品需求与边界

> 当前目标以主规格 §25、§19、§18 及未被覆盖的 §17 为准。条件式教学、永久删除和历史库接回的实际验证见验收记录末节；历史验收按日期保留。完整五模式体验仍待 Rex 验收，不以本轮回归代表 M1 放行。

## 当前修复边界

- 产品体验向安静的学习手册收敛，不新增模式/课程后台。消息、执行和学习目标分离，普通问答不强制显示学习计划。
- 知识整理交付即完成；资料学习讲完不等于掌握；问题攻克通过独立作答及追问即完成，拒绝入库不会挂起目标。保存是后续独立受控动作。
- 用户只看到可理解的失败影响和恢复动作；未开始自动恢复，失败手动重试，停止/归档后不自动继续。
- 标题下学习清单及完成小结来自持久化计划/评价，跳过/自述/验证分开，练习不改正式评分。Today 优先真实续学和复习，活动不代表掌握。
- 新旧待处理统一必要用户决定；来源可追溯，生成讲义不是外部证据；新会话交接必要相关进度而非全历史。
- OneWorks 抽象学习伙伴两版候选已实际制作，导出限制见品牌记录；本轮不重复制作，选定后精修。正式替换需 Rex 选择，不扩整套动画，不删除 V8。

Agent 与侧栏 + 进入独立起始草稿，首次发送本地原子保存后才创建可见会话；重复进入不清空草稿。快捷开始为六个可刷新场景，按 Harness §21 区分未编辑模板与用户草稿，可撤销、不调用模型或改变用户偏好。具体 Session 始终准确打开自身历史；切页不停止生成。

### 本轮新增的已确认目标（实现与验证分别见验收记录）

本文旧表述中的「用户确认后形成记忆」指正式知识卡入库，不指禁止保存可追溯的学习经历。学习记录、正式知识、复习评分分别维护。

- 个人学习教练不仅接住本次输入，还应在适当时用用户学过的知识举例、对比和建立关联，唤起可返回的知识卡或学习记录；不能编造用户经历或强行插入关联。
- 当前 Session 记忆、跨 Session 学习记录、正式知识/复习是三层不同对象。学习记录即使未入库也默认可跨会话用于教学，但不因此生成卡片、安排复习或认定掌握。
- 记录讲解、自述理解、独立作答证据及正式复习表现的时间和适用范围；「有卡片」「讲过」「到期」都不是永久掌握/遗忘结论。随堂回忆不写正式 FSRS。
- 归档是收纳，不等于遗忘；用户可独立排除某会话用于跨会话记忆，其历史保留、派生摘要/检索不再使用。已经保存的知识卡独立保留。跨会话不继承入库授权、未发送草稿或全部聊天。
- 初次使用浅色、默认今天；主导航为今天/Agent/知识库/待处理，学习会话区跨页面可见。输入区并列学习方式与思考强度，后者不是权限或付费档位；持久化规则见 Harness §18.2。
- 模型主备、错误局部修复和质量检查为内部规则；能恢复时不给用户模型切换通知，不能降低所选强度或扩大数据处理范围。无法恢复才说明影响和有效操作；质量不确定诚实表述，已显示错误明确更正。
- 读取允许的学习资料可自动执行；改目标、入库与覆盖知识仍有程序守卫。不增加常驻权限面板、通用工具市场或电脑操作。
- 听写与同 Session 语音聊天仅固化后续方向：听写清理后手动发送、可编辑撤销、不设标错入口；语音聊天保留当前学习上下文，不另开人物页面。模型与音频政策未在本次确定，不扩大 M1。

## 1. 产品定义

Review Today 是一个能够陪用户理解、形成记忆并主动复习的个人学习教练。用户只面对一个 Coach；Session 负责承载连续学习上下文，内部 Harness 根据目标选择受控工作流。

它不以收藏、笔记或知识图谱为核心，而是把用户每天接触的零碎内容持续转化为主动回忆训练：

```text
在学习 Session 中输入材料、主题、问题或 JD
→ Agent 立即反馈；Auto 自动调度知识整理、资料学习、主题探索或问题攻克的所需能力
→ 理解、核验、教学或练习
→ 经用户确认后形成可判断的知识与问题
→ 每日主动发起语音复习
→ 判断掌握程度并允许用户纠正
→ FSRS 动态安排下一次复习
```

核心 Aha moment 是：用户提出一个真实学习目标后，系统能立即接住、解释当前过程，帮助用户真正理解或独立作答，并在用户确认后把成果变成可长期复习的记忆。

### 2.1 当前里程碑一边界

里程碑一保留文字与公开链接输入、四种受控学习工作流、知识卡生成、一个可判断的问题、用户自然语言文字回答和独立评分。用户回答不做额外预结构化；系统保留原始回答，把结构化评分规格与原始回答一起交给评分模型。

## 3. 知识模型

### 3.1 三层结构

每次学习内容分为三个相互关联但职责不同的层级：

1. **来源**：用户原始文字、公开网页正文或明确标注的 Agent 生成讲义（语音为后续），回答“这条知识从哪里来”；生成讲义不等于独立外部证据。
2. **知识点**：Agent 从来源中拆出的单一学习目标，回答“用户具体要记住什么”。
3. **复习问题**：针对知识点生成并校验的问题，回答“如何主动回忆和判断是否掌握”。

一个来源可以生成多个知识点；一个知识点可以拥有主问题和最多两个经过校验的变体。问题变体共享同一个掌握状态和排期。

### 3.2 知识类型

- **事实**：需要记住明确结论、名称、时间、数字或关系。
- **概念**：需要用自己的话解释含义、边界、原因或区别。
- **程序**：需要说出完成任务的步骤、条件、顺序或判断方法。

语言不是第四种知识类型，而是独立属性。每条知识同时记录内容语言、提问语言和预期回答语言。

### 3.3 拆分与来源约束

- 一个知识点只保留一个主要学习目标，同时保留理解该目标所需的上下文。
- 每个知识点必须绑定来源中的短证据片段或可定位位置。
- 原始内容决定用户想学什么；Agent 不得把自身常识伪装成来源事实。
- 客观主张、来源观点和用户个人想法都可以入库，但必须明确归属，不能把观点改写为已证实事实。
- 每条知识只有一个主要主题。Agent 优先匹配已有主题，否则建议新主题；用户可以修改，不提供自由标签体系。

### 3.4 修订与版本

- 修改措辞但不改变学习目标时，可以保留现有掌握状态。
- 修改核心含义时生成新版本，旧复习历史继续指向旧版本，新版本重置 FSRS 状态。
- 复习提交前必须核对知识版本，过期评分不得覆盖用户刚刚修改的内容。

## 4. 学习 Session 与 Agent Harness

### 4.1 输入与入口

当前 M1 学习入口支持：

- 文字；
- 公开网页链接；
- Session 内连续追问与用户选择。

主窗口的“学习”工作区提供完整输入。Today 只展示学习与复习数据，不提供输入；语音、菜单栏采集和全局快捷键不属于当前 Harness V2 验收，也不持续监听屏幕、麦克风或其他 App。

主窗口只使用一条可收缩侧栏：今天、Agent、知识库、待处理四个主入口固定；其下会话区跨页可访问、可搜索/归档/独立滚动，支持按需多选。收起后保留图标栏，会话图标展开原列表，不设置第二栏或临时弹层。品牌仅单行 Review Today，设置/主题固定底部。会话仅标题、最多一个主题标签与必要状态符号，更多菜单处理管理动作。Agent 起始提供品牌、居中输入和六个可刷新的本地快捷开始；未编辑模板可切换，编辑后的草稿保留并追加，可撤销，不自动发送。正式会话使用轻量标题、居中对话和底部输入；学习方式/强度为独立单层菜单，保留学习/来源/受控操作，不加人物、积分、升级或文件夹。细节以 Harness §21 / DESIGN.md 为准。

Session 必须容易区分和管理：标题、运行状态、模式与主题标签可见；自动主题标签可由用户覆盖并恢复自动，知识关联标签只读。归档是直接操作，运行中归档先停止回复并保留历史，归档后可撤销或恢复；旧结果不能在归档后继续写回。

Today 在状态卡下显示最近 26 周活动热力图：只统计已完成的知识回答、资料学习步骤和正式复习，不把问候、打开、失败、preview 或未完成输出算作学习。保留中性的活跃天数、当前连续天数和最长连续天数，支持日期悬停、当日明细和准确对象跳转。“最近学习”默认三条，页面内展开后固定高度滚动全部进行中 Session。

输入首先是对话消息，不自动等同于学习任务、作答、确认或入库。知识整理先交付整理结果；所有正式入库都要求明确意愿和满足理解条件。

2026-09-04 已确认：学习输入支持 Return 发送、Shift Return 换行及中文输入法选词保护；未发送草稿按 Session 隔离。运行使用真实阶段与秒数，答案流式呈现，历史不重播；停止保留未完成内容，预览不等于已验证或可入库。普通完成状态收敛，对话不重复显示角色头像，侧栏品牌保留。纯问候、感谢和简单能力介绍可由 Luna 在识别时回应；知识问题、混合意图和操作仍走原有模型分工与程序检查。五模式产品边界不变，详见主规格 §15。

产品有五个模式：Auto、知识整理、资料学习、主题探索、问题攻克。Auto 普通问题先解答，裸资料先轻量整理；明确学习目标再启动完整流程。Auto 在同一目标内自动转接，重要操作需明确意愿。用户主动选择模式立即作用于当前目标并保留进度。教学由模型组织，新知识点自动搜索核对，相关追问复用已有资料，不设资料包确认门槛；个人记录和知识卡仅在相关且有效时参与关联，新用户也能直接开始学习。

### 4.2 本地优先任务

- 原始输入先写入 Mac 本地，再交给 Agent 处理。
- 离线时允许采集并进入待处理队列；联网后自动继续。
- 每轮输入拥有稳定消息 ID，每个学习目标拥有唯一 Task ID；统一状态为 `accepted → queued → running ↔ awaiting_user → committing → completed`。
- 异常状态为：`retryable_failed`、`needs_attention`、`cancelled`。
- 可重试失败采用有限退避，App 重启后继续；只有结果在 Mac 本地完整提交并确认后才算完成。
- 失败不能丢失原始输入，也不能留下半完成知识点。

### 4.3 Agent 处理流程

Harness 每个 Session 同时只有一个前台执行过程；可调用工作流局部能力，不要求每条消息跑完整链：

```text
本地保存消息并立即回显
→ 识别本轮意图、目标对象、Session 关系与候选工作流
→ 程序检查状态与授权，执行对话回应或工作流所需能力
→ 持续返回可解释的工作事件
→ 等待用户选择、回答或确认时暂停
→ 接受补充与纠正；Auto 同目标内自动调度，保留上下文
→ 用户确认后形成记忆并写入本地
```

- AI 负责理解和生成；程序负责流程、分支、重试、校验、排期与写入。
- 模型输出先做 JSON 结构校验，再做独立语义校验；最多自动修复一次，仍不通过则进入待处理。
- 路由、教学／生成和高风险验证是不同调用职责；内部主备须按 Harness §18.6 验证配置，不降低用户选定思考强度。2026-09-05 Rex 明确授权以 DeepSeek 官方作为主供应商，Flash 对应路由/教学，Pro 对应风险验证，具体契约见 §20；五模式与受控入库不变。当前配置和真实调用是否可用不能由产品文档代替验证。

### 4.4 模式与网页规则

- 网页仅支持无需登录的公开 HTTP 页面和正文提取，不启用无头浏览器。
- 抓取必须阻止本机地址、内网地址和其他 SSRF 风险；无法读取时保留链接并提示粘贴正文。
- 知识整理先梳理内容，理解与明确授权是正式入库条件，不是生成概览的前置条件；资料学习支持用户材料、网页及标注来源的生成讲义。
- 资料学习可按用户要求跳过检查并继续，保留未验证状态；自述理解不能替代问题攻克的独立作答。
- 运行中新输入默认及时纳入；明确排队则稍后处理。停止回复保留目标，取消目标终止任务，均保留历史。
- “我想一下”“稍等”等无副作用暂缓只做自然确认，不调用完整回答或学习流程，也不改变理解、待办、目标或队列；它不等同于停止、暂停目标或排队。
- 确认支持明确自然语言，必须绑定对象与版本；否定、条件、纠正和资料内指令不能误当授权。
- 问题攻克先给基础答案再校准，最终以用户能够独立作答或解决同类问题为完成标准。
- JD 先拆能力地图和优先问题，不一次生成整份答案。
- 语音采集与实时语音规则保留为长期方向，不属于本轮 M1。

### 4.5 回执和运行记录

- 学习工作区展示用户能理解的进度，例如“正在理解目标”“正在检查资料”“等你回答”“正在形成记忆”“需要处理”。
- 用户消息必须先在 Mac 本地保存并立即显示；服务未就绪时展示真实启动或恢复状态，不能只显示无限等待。
- 模型能力检查是后台服务诊断，不得伪装成当前消息的思考过程；服务可用时不以大横幅持续占用对话，实际能力受限使用紧凑提示，具体失败仍归属对应 Run。
- 每个任务可展开运行详情，查看节点、路由依据摘要、耗时、重试、错误和恢复动作。
- 开发模式继续提供跨 Task 的“Agent 运行记录”页，展示节点轨迹、分支原因、结构化输入输出摘要、耗时、重试和失败点。
- 运行记录不展示或保存模型隐藏思维链，也不得记录不必要的完整知识正文或密钥。

## 5. 风险核验与待处理

### 5.1 触发方式

风险由确定性规则和模型分类共同判断，任一方命中即触发核验。典型情形包括：

- 可能随时间变化的内容；
- 精确数字；
- 医学、法律或金融内容；
- 来源之间存在冲突；
- Agent 对事实可靠性不确定。

### 5.2 核验标准

- 先读取用户原始来源正文。
- 优先查找权威或一手来源，按其对具体结论的支持范围、时效与充分性判断；不固定要求两条来源，也不以数量替代可靠性。
- 核验只能补充限定、标记冲突或说明证据不足，不能悄悄改变用户的学习意图。
- 证据不足或冲突时，只暂停受影响的知识点，不阻塞同一来源下的其他知识。

### 5.3 冲突处理

冲突知识进入统一“待处理”中心，用户可以：

- 采用带限定条件的核验版本；
- 改记为“某来源的观点”；
- 继续暂停；
- 删除。

已知冲突的内容不能被用户强制标为“已确认事实”后进入复习。

## 6. 问题与评分标准

每个知识点的评估规格至少包含：

- 学习目标；
- 必须覆盖的关键点；
- 可接受的同义表达；
- 常见误解；
- 证据引用；
- 必要时的顺序规则；
- 一个主问题和最多两个经验证的问题变体。

不为关键点制造没有依据的虚假权重。评分依据语义是否正确，而不是是否复述固定句式。

## 7. 每日主动复习

### 7.1 通知闭环

- 用户设置每日提醒时间，由 macOS 本地通知调度，不要求 Python 服务常驻。
- 通知提供“现在开始”“15 分钟后”“1 小时后”“今日跳过”。
- 每天最多稍后两次，不连续催促。
- 当天没有符合条件的候选时不发通知，并记录“无需复习”。
- App 内始终保留手动开始入口。
- 系统记录实际开始、稍后和跳过；有足够行为数据后只能建议新时间，由用户确认后修改。

### 7.2 候选与顺序

- Mac 在会话开始时生成固定候选快照，数量略多于预计五分钟能完成的题目；会话中新增知识不插队。
- 优先级：逾期且曾答错 → 其他到期 → 新知识 → 有限提前复习。
- 新知识至少等待两小时才进入正式复习。
- 提前复习只选择未来 24 小时内到期的内容，每次最多两题；仍无候选就自然结束。
- 同一优先级内做软性交错：同一来源最多连续两题，条件允许时混合事实、概念和程序。
- 同一天的额外会话只使用仍然到期或尚未复习的新候选，不重复已完成题目，不提供无排期的自由练习模式。

### 7.3 五分钟与单题时长

- 五分钟限制的是“继续开始新题”的时间窗口，不是用户回答单题的硬截止时间。
- 五分钟到达后不再开新题，但允许当前题自然完成。
- 单题思考约一分钟时播放一次轻提示音，并显示“思考约 1 分钟，可继续回答、请求提示或跳过”。
- 提示不扣分、不强制结束；答题时长只作为行为数据记录，不能自动降低掌握等级。

### 7.4 语音交互

- 正式复习使用独立专注窗口，一次只处理一道题。
- 历史长期技术候选为 OpenAI Realtime；本轮只确认语音产品行为，不锁定供应商。无论最终选择何种语音层，问题选择、评分、提示次数和 FSRS 都不由其自主决定。
- 使用语音活动检测自动判断说话开始与结束，同时提供“我答完了”按钮和同义口令。
- 用户可以打断 Agent 播报。
- 说话时只显示聆听状态；答完后展示完整转写和评分。
- 用户选择“转写不对”时可以免费重录，不消耗学习提示次数，也不更新排期。
- Realtime 失败时先使用 macOS 系统语音朗读确定文本，再降级为纯文字问答。

### 7.5 提示、反馈与收尾

- 每题最多一次不泄露完整答案的提示和一次重答。
- 一道题最终只产生一个 FSRS 结果。
- 使用提示后即使答对，最高自动等级为 `Hard`。
- 即时反馈保持简短分层：先说明判断，再指出覆盖点或缺失点；详细记录在会后总结查看。
- 关闭复习窗口时进入“暂停并可恢复”；已完成题目立即保存，未完成题目恢复后重新提问。

## 8. 掌握等级、纠错与排期

### 8.1 掌握等级

- Agent 自动判断 `Again`、`Hard` 或 `Good`。
- `Easy` 只能由用户将 `Good` 主动升级得到。
- 语义正确性决定掌握等级；回答时长不自动扣分。
- 提示事件会限制最高等级，但不把所有求助都等同于完全不会。

### 8.2 用户纠正

- 用户可以把 Agent 判断改为 `Again`、`Hard`、`Good` 或 `Easy` 中的任意等级。
- 同时保留 Agent 原始等级和用户生效等级。
- 生效等级进入 FSRS，改判计入“判断纠错率”。
- 会话内改判只修正本次结果；会后可以进一步修订知识点、问题或评分规格，避免同类误判继续发生。

### 8.3 FSRS

- FSRS 是由表现数据计算下次日期的确定性间隔复习算法，运行在 Mac 客户端。
- Demo 使用固定算法版本和默认参数，不在实验中动态调参；每条历史记录保存算法和参数版本。
- 每个知识点只有一个 FSRS 状态，所有问题变体共享排期并轮换使用。
- Agent 只返回掌握等级，不直接指定下一次日期。

### 8.4 一题一事务

每题按照以下顺序完成：

```text
回答
→ 评分
→ 可选改判
→ Mac 原子写入复习历史与 FSRS 新状态
→ 返回提交确认
→ 下一题
```

每次尝试使用唯一 `attempt_id` 防止网络重试造成重复记账。没有收到 Mac 提交确认前，服务不能进入下一题。

## 9. 轻量知识库与生命周期

知识库只服务于查看、纠错和建立信任。用户可以：

- 按主题和掌握状态查看知识点；
- 查看来源、证据、当前掌握状态、下次复习和历史判断；
- 修改知识点、问题、评分规格、主题或语言；
- 暂停、恢复、软删除或永久删除；
- 处理核验冲突和 Agent 误判。

规则：

- 暂停或软删除可恢复；永久删除必须明确确认。
- 共享来源只有在不再被任何知识引用时才可随知识一起删除。
- 恢复知识时保留掌握历史，但从下一次正式会话重新进入排期，不制造逾期债务。
- 不提供文件夹体系、复杂标签、可视化知识图谱或独立知识库聊天入口；不禁止学习 Agent 按本轮目标检索已有知识、进行可追溯的关联教学。

## 10. 语言与输入替代

- 普通知识默认使用用户主语言提问。
- 用户可以显式选择“用中文复习”或“用目标语言复习”，覆盖 Agent 判断。
- 语言学习只判断知识含义和关键表达，不评分发音、流利度或完整语法能力。
- 正式复习允许文字回答，作为语音环境不合适或技术故障时的替代路径。

## 11. 数据与隐私边界

- 完整 Session 对话、结构化摘要、学习任务、运行事件、知识、来源、复习历史和 FSRS 状态保存在 Mac 本地。
- 本地 Agent 服务只接收当前任务或会话需要的最小内容，短期 checkpoint 到期后删除内容。
- 长期技术指标不得包含完整知识正文。
- 正式复习音频只保存在 Mac 本地并滚动保留七天，用于排查转写和评分问题；Review Today Agent 服务不保存音频，Demo／POC 结束时全部删除。
- 长期复习历史只保存轻度清理后的回答文字，不保存逐字原始转写。
- 外部 OpenAI 服务仍受其平台数据政策约束；“Review Today 不保存”不能被描述为“所有第三方均零留存”。
- POC 不录入敏感内容；自动处理材料视为用户允许按需发送给模型、转写和搜索服务。

## 12. 产品明确不做

- PDF、图片、外部音频文件或视频文件导入；
- 登录墙、付费墙和需要浏览器会话的网页抓取；
- 持续屏幕监听、持续麦克风监听、本地大模型或离线 AI；
- 通用个人助手、多角色 Agent 产品导航、开放式工具执行；学习 Session 内与当前目标相关的追问不受此条限制；
- 编程可作为学习主题，支持代码解释、报错原理与教学示例；不承接完整项目代做、修改仓库、实际运行调试/测试或部署。能力介绍不得将代码文本生成描述为上述开发服务（2026-09-16，A005）。
- 发音、流利度、语法和完整口语能力评分；
- 完整笔记管理、知识图谱、社区课程或复杂第二大脑；
- 首版全局快捷键；
- 当前阶段的 iOS、同步、正式登录、公共部署、订阅或付费墙。
