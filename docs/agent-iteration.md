# Agent 内测与回归迭代

## 工作方式

内测发现 → 登记候选 → 对齐预期 → 复现定位 → 修复 → 回归与原生体验验证 → 回写证据。每个实际修复按此流程推进，不等待完整评测工具建设。普通聊天不是自动加入的评测样本，也不会自动训练模型或修改提示词。

问题模板：编号、初始任务状态、必要上下文、输入、实际回答/执行记录、预期与禁止行为、出处、定位、修复版本、受控/真实模型/原生/Rex 验收结果。入仓库的样本使用脱敏或合成数据；待对齐样本不得冒充已有标准答案。

修改 Harness、提示词或知识入库前查看相关样本，先复现再修复，补测相邻场景，记录修复前后差异。功能实现、自动化通过、真实模型表现及 Rex 验收分开记录。

## 已确认行为

- 纯暂缓只简短回应、保留进度；不继续教学、追问或提示录入。
- 回答生成完不等于话题收尾。等待用户表达明白、完成或切换话题，再由 Harness 核对当前话题、完成状态及既有保存资格。模型提供结构化意图证据，正文不创建操作权限。
- 收尾在对话内显示固定面板。录入并继续：原面板播放 Spine，真实保存成功后续讲；稍后录入：内容版本及来源进入待处理，然后续讲；跳过：不创建待办、不重复催促，继续下一步。
- 下一步只来自用户已提出的请求；没有下一步时，处理后停留。以后从待处理录入不重新执行当初的续讲。
- 多个待录入话题分别保存，不能被下一份整理稿覆盖；重复动作、旧版本和重启不能重复保存或续讲。
- 保存仍遵循理解、问题攻克验证、来源、版本、生命周期及幂等检查。未满足时不因收尾推定已掌握。
- 核验说明作为次级提示，与回答和提问区分；复制保留说明。
- 编程仅作为学习主题：可解释代码、报错原理及教学示例；不承接项目代做、仓库修改、运行调试、测试或部署。能力介绍同样遵守此边界；超范围请求简短说明并提供学习方向，不创建开发目标、不触发录入。

## A005 案例与回归范围

- 出处：2026-09-16 Rex 提供的真实 App 截图；仓库仅保留必要问句与回答摘要，不导入私人会话。

- 实际：回答“可以，我能帮你写代码、读代码和排查问题”，继续介绍按需求实现、重构和项目整合。

## A006/A007 已确认规则与验收案例

- 新会话默认按本轮问题处理，跨会话知识只辅助解释。术语歧义、续学对象不明、执行目标切换分别判断；relation=uncertain 不单独触发反问。
- 用户纠正会话上下文时，核对实际记录并回到未回答的问题；不能重复同一澄清，也不能把对话纠错当知识错误清空理解。
- 首次路由不接收跨会话记忆正文；教学阶段按需检索，过滤“什么/如何”等问句词的虚假词面匹配。
- 用户明确续学且唯一匹配有效记录时，直接在新会话接续同一学习目标与进度；多个对象只问目标，没有记录如实说明。
- 归档不等于禁止引用，但旧会话不恢复执行；排除/删除/版本失效不得自动续接。交接不带旧确认或录入授权。
- 当前承接任务唯一，旧任务只保留历史与后续入口；重试、恢复、并发与迟到结果不能产生第二份有效进度。
- A006 脱敏输入：新会话“什么叫 harness”→错误续学反问→“我不是才和你聊天吗”→重复澄清。预期直接解释；若上一轮已问错，则简短纠正并解释原问题。
- A007 合成案例：RAG 课程停在检索步骤，新会话“继续上次没学完的 RAG”；唯一目标直接续学，多目标选择具体对象、无目标诚实说明。覆盖归档/排除/删除、源任务执行中、版本冲突、重复交接、重启及旧结果晚到。
- 本轮先交付 A006，再交付 A007；受控、真实模型、原生、迁移及 Rex 验收分别回写，不把规则确定当作实现完成。

### A006 验证（2026-09-17）

- 定位：relation=uncertain 被无条件转换为续学反问；首轮实际没有旧任务。后续纠正又被当作话题歧义。
- 修复：路由只用当前会话；澄清按内容/续学对象/操作分类；对话纠错回到原问题，不修改掌握状态。通用问句词不参与原生关联召回。
- 回归：324 项服务测试、34 个子场景通过；20 组原生契约及本地 SSE 检查通过。首次回归发现含糊目标不可直接建任务，已补回保护并复测。
- 真实模型：隔离库两轮完成，首问直接解释 harness；注入旧错误反问后，用户纠正触发简短纠错并回答原问题；均未建学习任务。见 [A006 证据](evidence/2026-09-17-dialogue-continuation/README.md)。

### A007 实现与验证（2026-09-17）

- 显式续学才选择未完成目标；当前会话事实、教学记忆和续学候选分开处理。唯一有效目标原子交接，多目标列出具体对象，无匹配不编造课程。
- 任务保留稳定 goal_id 与递增归属版本；交接前再检查来源、当前进度指纹及是否执行中。只复制学习进度/来源证据，旧确认、草稿与待提交写入不继承。
- Mac 持久化当前归属；今日学习中按目标去重。旧会话显示当前进度入口；旧步骤可回原会话查看。恢复快照、旧结果晚到和重试不能生成第二份有效进度。
- 新增真实失败案例：continue_goal 漏填续学字段导致凭空新建光合作用课程。现有硬性拦截和补判；真实模型复测无匹配时诚实说明，未建任务。
- 342 项完整服务回归/34 子场景、随后 26 项定向回归、21 套原生契约、本地 SSE、旧磁盘迁移、Debug 构建通过。真实模型 5 轮、原生隔离窗口历史导航/窄窗/深色/减少动态分别完成；日常开发版已加载修复。详见 [A006/A007 证据与剩余验收](evidence/2026-09-17-dialogue-continuation/README.md)。
