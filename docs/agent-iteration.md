## 案例基础规则（2026-09-17）

A001–A017 统一登记在 `agent-service/tests/fixtures/agent_cases/catalog.json`。文档保留产品决定与历史证据，目录负责可检查的来源、上下文完整度、预期、禁止行为和测试映射；两者不能各自新增未登记的案例编号。

- **原始发现与回归场景分开**：截图能证明的输入、前文与现象如实记录；缺失的内部状态标为未知，不根据截图猜定。合成前文和任务状态明确标为合成，即使输入逐字来自截图，也不称为原始会话复现。
- **固定上下文与生成式流程分开**：固定回放使用入库的前文、会话模式、任务/其他目标、暂停和待处理状态；当前任务必须关联到具体的请求/讲解消息。自动检查关联存在，维护者同时核对讲解与步骤是否一致。生成式多轮测试保留每轮实际起点，前轮模型生成内容不冒充固定输入。操作授权、网页故障和原生布局继续使用对应专项测试，不强行降为单句意图测试。
- **入库门槛**：来源、缺口、预期与禁止行为、受控测试位置必须齐全；可执行场景必须显式给定初始状态、关联案例及有效断言。重复编号、未知字段、失效引用、空场景、无行为断言、遗漏文档案例均阻断回归。尚不能固定回放的部分必须填写原因，不以一个场景宣称覆盖整条案例。
- **结果可追溯**：新格式记录测试层级、代码与场景摘要、提示词摘要、模型配置、实际前文/状态、识别与执行结果及每项断言。失败和未完成保留，空选择、未知编号、缺结果不算通过；结果文件不覆盖旧记录。
- **分层解释**：受控测试验证程序保护，真实模型固定回放验证给定上下文的行为，生成式多轮回放验证连续体验，原生检查验证展示。自动结果不代表自然度合格或 Rex 已验收。历史证据保留为旧格式，不倒填当时未记录的模型/版本/上下文。

本轮先建设这个基础，不做模型训练或大批量语句扩写。默认校验离线运行；真实模型回放必须显式启用，使用合成/脱敏夹具和隔离数据库，不读取日常聊天。固定对话基线阻断网页与知识写入，并记录调用企图；因此不能作为真实网页或录入成功的证据。

基础规则修复批次完成：13 条案例登记，19 个固定场景，结构/引用/文档覆盖门槛与结果完整性检查；A012/A013 的生成式多轮脚本接入分层报告。490 tests / 110 subtests 通过，当前版本的19个固定场景和9轮 A013 生成式流程自动通过。初轮场景前文与进度不一致的失败保留并修正夹具，不冒称产品回归。旧格式、专项执行器与人工评审边界见 [基础质量修复与证据](evidence/2026-09-17-case-library/README.md)；所有产品案例仍待 Rex 验收。

## A010 普通问答与学习任务边界（2026-09-17，已修复／待 Rex 验收）

真实复现：Auto 中“你好”→“我不知道”→“harness是什么，它有什么作用”，意图为 question，却同时标记 learning/topic_exploration/answer_only=false，程序误建任务并追问学习目标；搜索未运行。此前举例追问误入学习任务为同类问题。

修复契约：Auto 单纯问题、解释、举例、提示优先局部回答，不能仅凭 scope/workflow 建任务；显式学习目标、继续既有任务及用户选择的学习模式保持原行为。局部问答不要求确定学习用途，不展示新学习任务或录入提示。无证据不擅自把多义术语限定到某领域；先说明通用含义/区别，依据明确上下文解释，必要内容澄清与学习目标澄清分开。网页核验仍走独立工具链。基础首问简短讲定义/作用/一个例子，局部追问不重复背景；用户要一个类比只给一个，不自动展开教程（正文长度为提示目标，不截断模型输出）。

纠错：用户“我只是问它是什么/先回答问题”识别为对话纠错，回到尚未回答的原问题。只撤销可核实为普通问答误建、停在目标澄清且没有学习计划/成果的任务，保留历史；不能撤销用户明确建立的学习目标、其他任务、已学进度或保存数据。普通 Auto 问题即使遇到旧误建任务也应能继续回答。

## 工作方式

内测发现 → 登记候选 → 对齐预期 → 复现定位 → 修复 → 回归与原生体验验证 → 回写证据。每个实际修复按此流程推进，不等待完整评测工具建设。普通聊天不是自动加入的评测样本，也不会自动训练模型或修改提示词。

修改 Harness、提示词或知识入库前查看相关样本，先复现再修复，补测相邻场景，记录修复前后差异。功能实现、自动化通过、真实模型表现及 Rex 验收分开记录。

## A006/A007 已确认规则与验收案例

- 新会话默认按本轮问题处理，跨会话知识只辅助解释。术语歧义、续学对象不明、执行目标切换分别判断；relation=uncertain 不单独触发反问。

- 首次路由不接收跨会话记忆正文；教学阶段按需检索，过滤“什么/如何”等问句词的虚假词面匹配。
