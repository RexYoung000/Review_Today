## A011 按需核验、运行反馈与来源链接（2026-09-17，已实现／受控与真实回放通过／待 Rex 验收）

Rex 确认：稳定概念、基础原理和普通举例优先使用模型已有知识；新知识点或没有网页证据本身不触发联网。用户明确搜索/出处核验、时效问题、高风险实际建议、证据冲突或知识不确定时才检索；指定 URL 继续走正文读取。同主题普通追问可复用适用证据，新主题不继承旧证据。未检索不追加失败提示，也不编造来源。

修复范围：移除强制搜索条件；路由语义明确核验需求。普通核验先读取最相关来源并判断支持范围，足够即停止；不足再读，最多三篇。明确交叉核验或高风险强制核验至少检查两个独立域名，来源不足如实说明。普通核验网页累计预算 30 秒、交叉/高风险 60 秒（仅工具等待/执行，不含模型）；不修改现有服务凭证、限流或备用顺序。

## A010 普通问答与学习任务边界（2026-09-17，已修复／待 Rex 验收）

真实复现：Auto 中“你好”→“我不知道”→“harness是什么，它有什么作用”，意图为 question，却同时标记 learning/topic_exploration/answer_only=false，程序误建任务并追问学习目标；搜索未运行。此前举例追问误入学习任务为同类问题。

修复契约：Auto 单纯问题、解释、举例、提示优先局部回答，不能仅凭 scope/workflow 建任务；显式学习目标、继续既有任务及用户选择的学习模式保持原行为。局部问答不要求确定学习用途，不展示新学习任务或录入提示。无证据不擅自把多义术语限定到某领域；先说明通用含义/区别，依据明确上下文解释，必要内容澄清与学习目标澄清分开。网页核验仍走独立工具链。基础首问简短讲定义/作用/一个例子，局部追问不重复背景；用户要一个类比只给一个，不自动展开教程（正文长度为提示目标，不截断模型输出）。

纠错：用户“我只是问它是什么/先回答问题”识别为对话纠错，回到尚未回答的原问题。只撤销可核实为普通问答误建、停在目标澄清且没有学习计划/成果的任务，保留历史；不能撤销用户明确建立的学习目标、其他任务、已学进度或保存数据。普通 Auto 问题即使遇到旧误建任务也应能继续回答。

回归：真实三轮会话；无历史首问；同概念举例；旧误建任务纠错与继续提问；正常显式学习与非 Auto；已有真实任务局部问答保持进度；有实际对象歧义仍可澄清；新主题局部问答不强制会话选择；网页核验与来源复用。419 tests / 69 subtests 通过，真实三轮会话、局部类比及注入旧任务后的真实纠错回放均通过。证据与重跑入口见 [A010 验证记录](evidence/2026-09-17-ordinary-question/README.md)。

## 工作方式

内测发现 → 登记候选 → 对齐预期 → 复现定位 → 修复 → 回归与原生体验验证 → 回写证据。每个实际修复按此流程推进，不等待完整评测工具建设。普通聊天不是自动加入的评测样本，也不会自动训练模型或修改提示词。

问题模板：编号、初始任务状态、必要上下文、输入、实际回答/执行记录、预期与禁止行为、出处、定位、修复版本、受控/真实模型/原生/Rex 验收结果。入仓库的样本使用脱敏或合成数据；待对齐样本不得冒充已有标准答案。

修改 Harness、提示词或知识入库前查看相关样本，先复现再修复，补测相邻场景，记录修复前后差异。功能实现、自动化通过、真实模型表现及 Rex 验收分开记录。

## 已确认行为

- 纯暂缓只简短回应、保留进度；不继续教学、追问或提示录入。
- 回答生成完不等于话题收尾。等待用户表达明白、完成或切换话题，再由 Harness 核对当前话题、完成状态及既有保存资格。模型提供结构化意图证据，正文不创建操作权限。
- 收尾在对话内显示固定面板。录入并继续：原面板播放 Spine，真实保存成功后续讲；稍后录入：内容版本及来源进入待处理，然后续讲；跳过：不创建待办、不重复催促，继续下一步。
- 下一步只来自用户已提出的请求；没有下一步时，处理后停留。以后从待处理录入不重新执行当初的续讲。
- 多个待录入话题分别保存，不能被下一份整理稿覆盖；重复动作、旧版本和重启不能重复保存或续讲。
- 保存仍遵循理解、问题攻克验证、来源、版本、生命周期及幂等检查。未满足时不因收尾推定已掌握。
- 核验说明作为次级提示，与回答和提问区分；复制保留说明。
- 编程仅作为学习主题：可解释代码、报错原理及教学示例；不承接项目代做、仓库修改、运行调试、测试或部署。能力介绍同样遵守此边界；超范围请求简短说明并提供学习方向，不创建开发目标、不触发录入。

### A008 Exa 接入（2026-09-17，已实现并通过真实链路验证）
