## 问答证据与知识卡生成闭环（2026-10-03，历史工程定向通过／10-04 曾发现状态指代回归／原生闭环待验）

保存状态回答必须依据当前会话实际草稿、收尾面板、生成任务与本机提交回执，区分旧卡引用、已讲解／作答、待整理、待确认、生成中、已保存和失败。询问“有没有生成／记录”“怎么生成”时说明实际停留点及下一步；不能用通用能力介绍、隐私说明或相关旧卡代替。当前问题作答通过不自动入库；用户明确收尾后显示既有录入面板，或明确要求保存后走既有授权流程，真实写入成功才称已保存。不在每次讲解后重复催促保存。
